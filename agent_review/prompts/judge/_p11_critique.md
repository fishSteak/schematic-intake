# 深审 · 难例续聊（通用追问）

适用于 Agent 深审白名单内、已有 `.analysis.md` 的检查项。本轮只做一件事：把过程写得更透。

完成一遍核对、修正文中的错误并记录未解边界后，即结束本轮。现有材料无法闭合的条件写清影响和补证动作，不以所有缺口清零为停手标准，也不生成额外图片。

通用追问（不要点名任何具体器件类型，不要为显得完整而堆工况）：

1. 省略旁支的直流平衡与是否长期稳态写清了吗？
2. 拓扑/半幅上界的成立条件写了吗？
3. 主依据的钉电位与灌拉路径是否可证伪？
4. 路径上有二极管/开关等时，对象端压是否误用了远端节点电压？
5. 对每个决定平衡的节点，重新从网表枚举全部引脚并在分析列支路审计表：引脚、直流去向、导通条件、计入方程或省略依据。按芯片功能检查受控通道及后接负载，不可一概称作高阻输入。漏支路必须重算，且解释忽略该支路会使对象应力增大还是减小。
6. 区分工程模型、严格上下界与全局最大值。已有可达超限反例不需要先求全局最大值；模型适用性不足则明确缺口，而不是伪造保证下界。
7. 有较重候选时，较轻超限对照不能替代最坏通路搜索。比较不同开关、钳位和接口状态及其持续性；有条件可计算的状态保留模型数字及条件，并与已确认状态分开排名。每张图仅描述该状态导通的路径；只写图的页码、路径、标注需求，不执行绘图、不在分析中嵌入 SVG/位图/base64，统一由后续 figure 渲染器出图。

有缺口 → **改正文 `.analysis.md`**；必要时同步改 JSON，使汇总与分析一致。  
禁止写 `context_store`；禁止改其他对象/rule。
