# Judge · P12-A07 · 落判定卡

**名称**：连接器电流 / 插拔寿命 / 防护覆盖需求  
**严重度**：严重

分析为主依据；本轮只压缩 JSON。`verdict_zh` 必须由分析汇总。

## 判据

电流、插拔寿命、防护分列比较；适用子项均覆盖才可整项「是」。不得自造 70%/1000 次等通用门槛。

## 口径

- 任务书无整机需求（电流 / 插拔 / 防护）→ **不适用**（编排通常已整项门禁）。  
- 有需求、缺厂家额定 → **待确认**。  
- 有两侧且不覆盖 → **否**。

## 落卡

读 `.analysis.md` + 工作台。  
- 电流子项：`states[]` 只留最差载流一条，标 `role` 为 `worst`，并写 `why_worst`。`figure` 只画载流通路（网名、连接器、对端）。插拔寿命和防护等级写在 `electrical`，不写成工况，不画图。
- 任务书没有电流需求时，不写 `states`，不写 `figure`。
**是/否/待确认**均必填 `headline_zh`（见 `_common_judge`）。禁止改 `context_store`。


## 现行适用性口径（覆盖上文旧入口排除说明）
有实际器件时，不因工作台任务书字段为空直接判不适用。先核原始任务书与已确认公共标准；明确适用的已确认基准可以使用并给来源。确无决定性项目需求时分子项保留可推导的已有结论，剩余影响判定的真实业务事实如实待确认。温区检查只按本项规则要求核对温区，不把未要求的全部自热证明无限扩大为本项阻塞条件。
