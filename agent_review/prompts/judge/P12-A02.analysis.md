## 分析时注意（整类）

- 区分推挽 / 开漏 / 双向；写清谁发送、谁接收。  
- 比较：VOH_min≥VIH_min、VOL_max≤VIL_max；输入耐压若相关则交代。  
- 同电源域不等于已经兼容。
- 正式工况只留最坏供电、温度、负载合成的一条。写清发送端脚、信号网、接收端脚，供通路图使用。
