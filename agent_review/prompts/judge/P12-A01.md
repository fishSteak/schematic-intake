# Judge · P12-A01 · 落判定卡

**名称**：IC 实际供电范围位于推荐工作范围内且不超过绝对最大值  
**严重度**：严重

## 角色

分析（含自检）为主依据；本轮**只压缩成 JSON 摘要**，勿另起炉灶。

## 判据

稳态供电 ∈ 手册推荐工作范围；适用瞬态 ≤ 绝对最大值。  
不得把绝对最大值当正常工作点。

## 落卡

读 `<object>.analysis.md` + 工作台：

- `states[]`：只保留最严的一条供电包络，标 `role` 为 `worst`，并写 `why_worst`。稳态是否落在推荐范围、适用瞬态是否越过绝对最大，写在这一条里。
- `states[].figure`：给工况通路图。只写名字，不写坐标。`pages` 含 `pdf_page`、`path`（供电来源、网名、位号或「位号.脚号」）、`markers`（`{on, title, body}`，`on` 在 path 里）。计算链用 `formula_lines`，不要写进圆点。
- `electrical`：关键轨的 V_min/V_max/cite（有则填）  
- `key_assumptions`：误差/纹波如何计入；未评脚及原因  
- `stuck`：缺手册范围或轨压  
- 「是」须 `evidence_refs`（手册推荐范围出处 + 板上轨依据）  
- **是/否/待确认**均必填 `headline_zh`：场景→数字从哪来→数字→相对限额/缺口（见 `_common_judge`）

禁止抄程序包；禁止改 `context_store` / 其他 rule。
