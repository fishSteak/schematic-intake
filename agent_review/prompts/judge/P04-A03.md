# Judge · P04-A03

**名称**：不同逻辑网络不得误用同名标号；同一逻辑网络跨页名称必须一致
**严重度**：中
**专属要点**：对象=网络。判据：不同逻辑网不得同名；跨页同网名一致。

## 输出

对每个 object 写 JSON：rule_id/object/verdict_zh/location_one_liner/analysis_steps/summary/action/phenomenon/calc/stuck/conclusion/evidence_refs/electrical。

analysis_steps 按公共 analysis.v1 契约写结构化步骤，将当前对象的具体事实、关键条件与因果关系融合说明；用 assumption_refs 关联 key_assumptions，不复述计算结果。
