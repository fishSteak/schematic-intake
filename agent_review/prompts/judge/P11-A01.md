# Judge · P11-A01 · 落判定卡

**名称**：电阻最大稳态耗散功率≤额定功率×50%  
**严重度**：严重

## 角色

分析文件（含自检修订）已就绪。本轮**只把分析压缩成 JSON 摘要**（门禁/列表索引），勿另起炉灶。  
`verdict_zh` 必须由分析中已成立的正常设计工程依据汇总；`P_max` 只在最坏工作包络闭合时填写。分析已否定或不自洽的态，不得编成完好稳态数字。执行共用功耗工程判定契约及 decision_audit，不得把缺精确最大值等同于不能判否。

## 输入

1. `review_out/agent_jobs/P11-A01/<object>.analysis.md`（主依据）  
2. 工作台 `.context.json`  
3. 需要时再读手册 / `context_store`  

禁止抄 `program_reference` 的态名/`P_max`/`completeness`。

## 判据

`P_max ≤ 0.5 × P_rated`（`P_limit`）。  
`P_max` = 分析认定的**长期直流可达**态中最大稳态功耗。

判定与全局最大值分开：正常设计核算超限可按共用契约用 normal_design_model 判否；严格可达证据用 reachable_state，保证下界用 proven_lower_bound。通过仍需要完整工作包络的上界。全局最大值未知时 electrical.P_max=null，decision_basis 另记 state_index/value_w/limit_w/evidence/conditions；normal_design_model 另记 model_scope/applicability/coverage_argument。待确认必须通过 decision_audit 证明缺口可能改变判定。不得把工程模型称作实物保证值，也不得因缺保证最大值而撤销工程判否。

原材料中的已确认粗估功率、预算或默认采用值只能按其证据范围使用；不能仅将它换算为 W、与限额比较，就命名为完整长期工作包络的上界。若必要周期或供能边界仍未闭合且没有独立充分依据覆盖，保留未完成证明及其判定影响，不通过删除工况、重标 maximum_only 或缩窄检查范围来改判通过。

## 落卡

业务展示只保留一个决定结论的极值工况：本项为最坏工况。只有该状态写 `figure`，其他状态仅写数字及一句比较理由，不绘制其工况图。跨页可有多张图，但必须属于同一个主工况。对有条件的数值对照使用“模型超限/模型内满足限额”，不把条件计算对照称作正式“是/否”。

面向业务的端压写成 `V(<对象>) 两端电压差 = …`，不要用虚构节点变量或 `V(<对象>.脚号)` 相减作为展示表达。实际脚号仅保留在内部路径/证据定位中，不能混淆节点电压与对象端压。推理正文用几句话说明依据、比较和结果，完整引脚审计及材料参数作为按需展开的证据。

按分析写出必要字段；必须保留最坏通路比较的结果，不得仅以较轻的超限见证替代最坏工况。不要为凑数量新增无关状态。

- `worst_case`：对象，含 `confirmed_state_index`（未确认则 null）、`conditional_state_index`（没有则 null）、`comparison`（逐项含 `state_index`、`reason`，覆盖每个 states 状态，说明较轻/最坏/无法比较的原因）、`unresolved`（尚可能改变排名的边界，数组）。两个索引均指向 states；confirmed 指已闭合且可持续状态，conditional 指有明确连接与建模条件的条件状态。没有全局保证值时仍保留条件最坏及其数值，不能全部塞进 unmapped。
- 每个条件状态用 `status=conditional`、`stress_kind=modeled`、`P` 数值、`conditions`（明确模型和待确认条件）、`why_worst`（比较依据），其中排名最高者用 `role=worst_candidate`；已确认最坏用 `role=worst`。对照用 `role=comparison`。条件状态不能用作已确认可达的否决见证，也不能代填 electrical.P_max。条件数值表示在所列前提下的估算，与真正缺少连接/模型的 status=unmapped 区分。

- `states[]`：保留决定结论的稳态及必要对照；`name_zh` 写通路；`P`；`结论`；`formula_lines: [{expr, src}, …]`；`stress_kind=modeled|lower_bound|upper_bound|exact` 区分数值性质。同一通路的参数档位合并说明。
- `states[].figure`：给工况通路图。只写名字，不写坐标。`pages` 每页含 `pdf_page`、主路 `path`（网名、位号或「位号.脚号」，按电流顺序）；有并联支路时用 `paths` 数组，每条路径独立列出。`markers` 为 `{on, title, body}`，on 属于任一路径，文字只写该点事实。多脚器件必须保留脚号并在 `through_body: [{ref, from, to, note}]` 明确内部转接。跨页网在各页分别终止和继续，禁止跨空白直连。计算链仍用 `formula_lines`，不要写进圆点。
- 图中 `path/paths` 只能包含本状态实际导通的电流支路，不得把截止支路、驱动控制线、其他状态路径当电流高亮。截止器件可通过 markers 标注并保留原图；markers 的 on 可为本页未导通器件。`markers.kind=volt` 可标节点电压，title 为带网名/位号的电压，body 留空。每个主图要有关键节点电压及对象端压标注，formula_lines 给供电、串联阻值、非线性压降、I、对象电压和功耗。每页可写 `label`（该工况状态）、`notes`（假设/截止说明），文字会画进图。
- `electrical`：`P_rated/P_limit/P_max/cite`  
- 若候选尚未闭合：保留 `status=unmapped`、`role=unmapped` 记录，明确缺口、`P=null`；不得覆盖其他已闭合的决定性状态。若全局包络未闭合，`electrical.P_max=null`。
- `key_assumptions`：**必须**含主依据态的闭合前提（谁钉电位 / 电流如何灌拉）；路径有串联非线性件时注明端压如何从节点电压得到  
- `stuck` 或 `key_assumptions`：未计入 `P_max` 的边界及原因；被省略的旁支若存在直流平衡点，**一两句**写清是否长期稳态、为何不进/不抬高 P_max（勿新开凑态）  
- `summary`：写清最坏态与是否依赖接口包络/外部灌拉；勿暗示「合法电压范围 = 已直接钉在电阻出口」；若引用拓扑上界，带上成立条件  
- **是/否/待确认**均必填 `headline_zh`：场景→数字从哪来→数字→相对限额/缺口（见 `_common_judge`）；勿写拓扑多步  
- 「是」须 `evidence_refs`；缺额定不得升「是」

可选：若主依据依赖外部灌拉或接口包络，用**一个**板内对照态（或 summary 一句）说明结论不单靠该前提——不要为此堆态；对照上界须写清忽略了哪些支路。

## basis-main.v1 主分析（优先于上文“最坏通路主图”的旧兼容要求）

新直接 LLM 的本检查项工作台声明 main_analysis_contract=basis-main.v1，必须按应用提供的对应 Schema 输出 main_analysis，不能省略以退回旧卡要求；这是正式判定依据的唯一主展示，不另选条件候选。根对象同时提供 analysis_contract="analysis.v1"、统一 analysis_steps 与结构化 key_assumptions，不重复旧前提/思路字段。历史卡读取和 review.v1 的独立合同不在此改变。

main_analysis.basis_ref 固定 `/decision_basis`，state_index 必须与 decision_basis.state_index 相同，计算直接引用该 states 项的 formula_lines/P。kind 为 cross_case_bound（正式依据 envelope_upper_bound，state.stress_kind=upper_bound）、operating_case（已支持的具体依据）或 incomplete_proof（decision_basis.kind=insufficient、待确认）。不得把上界当实际可达最大点；没有证明就不填伪数字。incomplete_proof 可在一个 status=unmapped、P=null 的计算项保留已完成等式及未闭合步骤。

main_analysis 含 title、route_summary（一句具体解释依据的供能/储能/耗散推导）、scope.included/excluded、assumption_refs（本卡 key_assumptions 的 ID）、proof_status、proof_checks（逐项 claim/status/reason/evidence_refs）及 figure。已支持的证明检查引用本卡 evidence_refs 中的 id 或 path；关键前提不能依赖未确认假设。通过/不通过需 proof_status=verified 且各证明义务 supported，不能靠把缺口改叫“精度问题”过门禁。

所有主图数据只归 main_analysis.figure 所有，states[].figure 全部省略或 null；候选仅作文字对照。figure.kind 为 cross_case_relations 或 operating_path，pages 每项按 Schema 给 pdf_page/label/route_summary/paths/markers，可附 relation_role=source/storage/dissipation/return/combined、through_body、notes。上界图按实际推导分组，不是某个瞬时状态；程序默认去掉跨状态的电流箭头，关系与器件内部功能须说明。节点没有唯一电压时不造电压。对象上界/限额标注可使用 quantity_ref="/decision_basis/value_w" 或 "/electrical/P_limit"，渲染器读取正式数值；title 只写量名，不再抄一份数字。

证明未完成时，decision_audit.gaps 中 can_change_verdict 可用 proof_gap:{failed_claim,reason,evidence,decision_effect} 说明待完成的必要证明，不需要编造物理超限反例。内部推导缺口写 reasoning 请求并继续自主查证；只有真正无法从材料取得的项目事实才向业务提出最小问题。不能为了保留通过结论强行补齐。
