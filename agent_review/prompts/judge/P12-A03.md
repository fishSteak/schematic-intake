# Judge · P12-A03 · 落判定卡

**名称**：有源器件温度等级覆盖项目最低/最高环境温度  
**严重度**：严重

分析为主依据；本轮只压缩 JSON。`verdict_zh` 必须由分析汇总。

## 判据

工作温度范围覆盖项目环境；不得以存储温度冒充；自热结温/壳温不超限（结温证据不足可旁证写缺口，主轴以 Tamb⊆T_op 为准）。

## 口径

- 任务书无 Tamb → **不适用**（编排通常已整项门禁；单卡若仍缺则同判）。  
- 有 Tamb、无手册工作温区 → **待确认**。  
- 有 Tamb 且工作温区覆盖 → **是**；项目窗超出 → **否**。

## 落卡

读 `.analysis.md` + 工作台：`electrical`（Tamb / T_op_min/max / cite）、key_assumptions、stuck、evidence_refs。  
只作温度额定与需求对照时不写工况图。若需实际供流、负载或自热模型才能判断，完成必要分析，给唯一主分析 states 与原图关系；尚未证明时保留具体失败步骤，不把条件热预算当实际耗散。
「是」须手册工作温度出处 + 项目环境出处。  
**是/否/待确认**均必填 `headline_zh`（见 `_common_judge`）。禁止改 `context_store`。


## 现行适用性口径（覆盖上文旧入口排除说明）
有实际器件时，不因工作台任务书字段为空直接判不适用。先核原始任务书与已确认公共标准；明确适用的已确认基准可以使用并给来源。确无决定性项目需求时分子项保留可推导的已有结论，剩余影响判定的真实业务事实如实待确认。温区检查只按本项规则要求核对温区，不把未要求的全部自热证明无限扩大为本项阻塞条件。
