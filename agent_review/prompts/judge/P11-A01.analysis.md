## 必须完成的最坏通路比较

报告主结果是工作范围内最坏通路及其功耗，不能在找到一个超限状态后停止搜索。先按实际网表和控制功能枚举会改变电流的开关状态、钳位状态、接口负载端点及其组合；排除不相容的组合并说明依据。正常持续状态、周期状态、启动瞬态及故障条件分别比较，不能混为最大稳态。

正文必须有比较表：状态/电流路径/导通与截止器件/闭合条件/对象电流、端压和功耗/持续性依据/是否进入比较及原因。用方程、单调性或界限说明为何其他通路不会更坏。未知控制状态不能只逐个标“未证明可持续”后结束：检查变化方向，能否用所有状态共有的边界推理；周期运行使用电流有效值求长期耗散，不把峰值当平均值。

数值可计算而真正依赖未证实的驱动或外部能力时，保留条件候选及数值，与正常设计模型分组排名；不能丢掉最严重候选，也不能把有出处的正常设计模型一概归为条件候选。仅影响参数精度的缺口不等于状态不可用于工程判定。典型值不能称作保证值，条件排名不能称作已确认全局最大值。

最后明确：已确认范围最坏是谁；条件模型中最坏是谁；二者功耗与额定/限额；还有哪一个未解边界可能超过它。如果不能确认全局最大值，要给出已有比较和最大候选的数值与闭合条件，不能只输出“待确认”。即使已有充分否决证据，最坏通路搜索仍须完成。

图的主视图必须对应正式判定依据，而非独立的候选排名。上界支持判定时主展示就是上界推导；具体工况支持判定时展示该工况；证明尚未完成则显示证明义务和卡点。未证实候选仅在必要时作文字辅助比较。每张图只画该状态的导通路径，不把互斥状态的支路叠成一张候选总连接图。沿原图真实铜线标电流箭头；标出开关/钳位的工作状态、关键节点电压、对象端压、电流、功耗及计算前提。未导通支路保留原图，不高亮；并联导通支路分别画，不串接。

本轮仅提供每个状态的路径名字、页码、节点电压和标注需求，不执行绘图脚本、不写 SVG/位图/base64，也不向 Markdown 嵌图。后续 JSON figure 契约交给统一渲染器沿原图铜线出图；不要将时间消耗在手工绘制另一套图上。

## 分析时注意（整类，非某器件清单）

- 任务书/接口给出的电压范围，要落到「谁钉电位、电流如何闭合」才可当长期稳态主依据。  
- 对象两端电压不要与隔着二极管/开关的远端节点电压混用。  
- 正式工况保留决定结论的长期稳态及必要的对照。同一通路的参数档位合并说明，不能因追求唯一全局最坏态而丢弃已闭合的超限证据。主依据、闭合前提、未计入包络的边界要写清楚。  
- 省略的旁支：若有直流平衡点，一两句写清是否长期稳态、是否抬高 P_max——不要为此堆正式工况。  
- 拓扑/半幅上界必须写成立条件（忽略了哪条支路、何种端态），勿写成无条件绝对最大值。

## 额定字段

工作台 `mpn_excerpt.params` 是本检查项额定字段；`material_params` 和邻件 `pintable.params` 包含建模所需的其他参数。读取相应来源、页码、测试条件和制造商适用性；存在冲突或条件不明时可回查缓存 PDF，不重复抽已明确的相同字段。缺失字段写明影响，只有它可能改变结论且无独立充分证据时才判「待确认」。

## 判定证据契约

- 「是」需要覆盖所要求的长期工作包络，并以可信上界证明全部不超限。
- 「否」可由材料支持的正常设计核算超限、可达稳态或适用下界支持；按共用功耗工程判定契约说明适用范围与证据层级。无需先知道全局最大值，也不要求标称工程模型先升级为全温保证。
- 典型值模型结果、保证下界、保证上界、已闭合包络最大值必须区分。典型模型超限是工程风险证据，不能伪装成保证下界；说明模型适用性及结论置信度。
- 求解非线性负载时检查支路电流平衡和工作区。测试电流、拐点测试条件、动态阻抗分别是什么，不得把局部小信号参数擅自当成全域直流保证。
- 对每个决定平衡的节点，按网表核对全部相连引脚，列出支路审计表：位号/脚号、直流去向、导通条件、计入方程或省略理由。集成器件的引脚不等于高阻输入，须按功能和引脚定义判断；受控通道在相关控制状态下的负载必须计入。未知条件写清简化模型省略的支路会使对象功耗增大还是减小，不能无解释地漏支路。
- 对缺口逐项说明：是否会改变已有决定性证据；若会，缺什么材料；若不会，保留判定并限定数值范围。不得把尚未确定的全局最大值填成精确数字。

## 正式依据独立复核与主分析（工作台启用 basis-main.v1 时）

只从当前原始材料重新建立连接、支路方程、储能/功率平衡和判据，不读取旧报告、历史评审卡或文档样例，不以旧结论为目标。对拟采用的任何上界，独立核对：逐节点 KCL、每个能量源和储能元件、符号与平方不等式、长期平均/初末能量条件、器件输入/输出模型的测试范围、源电压包络如何由材料或完整电路保证、阻值行程与容差、额定是否适用于有效阻段。数值复算只是其中一项，不能替代适用性证明。

在分析中明确每项证明义务的原始出处、推导及已支持/未完成/被否定状态。材料足够时继续推导或另建有效保守界，不把内部未完成推理交给业务。保守上界已经覆盖所需范围时，无需为求精确最大值机械枚举；“没有发现超限”不是通过证明。若关键包络或能量项仍未被支持，不将其包装成已验证上界，写清具体 proof_gap，并如实待确认。

主分析只引用最终 decision_basis；后续 JSON main_analysis 指定是 operating_case、cross_case_bound 或 incomplete_proof。上界关系图标出实际供能、储能、耗散与回流关系，分组/分区说明，不假设各边界同时取等，不把互斥状态叠成实际通流图；关系未有统一方向时不画电流箭头。图中的对象上界/限额引用正式依据的量，不另造更好画的具体电位组合。
