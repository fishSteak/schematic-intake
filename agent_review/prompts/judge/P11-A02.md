# Judge · P11-A02 · 落判定卡

**名称**：高压回路电阻最大工作电压≤额定耐压×50%
**严重度**：严重

## 角色

分析（含自检）为主依据；本轮**只压缩成 JSON 摘要**，勿另起炉灶。
缺额定耐压或端电压不得升「是」。非高压回路用「不适用」。

## 判据

- 只判高压回路：V_max ≤ 0.5 × V_rated
- 非高压回路整颗不适用，不要另开应力态
- 不适用的 summary / headline_zh 必须保留分析中已查证的实际供电/接口范围、未发现高压用途的具体依据与本项范围说明；不得只写“低压所以不适用”，不得以器件额定耐压替代适用性理由。全板排除必须有全板材料核查依据，不能从单只电阻外推。不得将正常标称电压表述为所有节点、瞬态的绝对上限。

## 落卡

读 `<object>.analysis.md` + 工作台：

- `electrical`：写入 V_max、V_rated、比值（有则填）
- `states[]`：只保留最差的一条长期稳态，标 `role` 为 `worst`，并写 `why_worst`。不适用则 `states` 为空
- `states[].figure`：给工况通路图。只写名字，不写坐标，不指定圆点方框放哪。`pages` 每页含 `pdf_page`、`path`（网名、位号或「位号.脚号」，按电流顺序）、`markers`（`{on, title, body}`，`on` 必须在 path 里；title 短，body 只写这一点上看得见的事实）、可选 `through_body`（`{ref, from, to, note}`，只描述封装内部）。计算链仍用 `formula_lines`，不要写进圆点。
- `stuck`：缺耐压或端电压时写卡点
- **是/否/待确认**均必填 `headline_zh`

禁止抄程序包数字；禁止改 `context_store` / 其他 rule。
