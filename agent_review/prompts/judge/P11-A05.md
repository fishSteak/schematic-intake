# Judge · P11-A05 · 落判定卡

仅“任务书未提出高温要求”或“没有热源证据”不足以证明不适用。由 Agent 依据判据和材料论证未知适用条件是否会改变结论；有覆盖论证时，不仅因字段未齐就挂待确认。落卡保留真正影响判定的边界，不得在压缩时把未知条件改成否定事实。

**名称**：高温场景陶瓷电容使用 X7R/X5R 或项目批准介质，不使用 Y5V
**严重度**：中

## 角色

分析为主依据。非陶瓷或无高温场景用「不适用」。介质缺失用「待确认」，不得升「是」。

## 判据

- 高温场景陶瓷：X7R / X5R，或书面批准的介质
- Y5V → 否

## 落卡

- `electrical`：介质代号、高温依据（任务书温度或邻近热源）
- 本项不写 `states`，不写 `figure`
- **是/否/待确认**均必填 `headline_zh`

禁止改 `context_store` / 其他 rule。
