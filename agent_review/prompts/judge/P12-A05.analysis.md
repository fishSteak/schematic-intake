# Judge · P12-A05 · 分析

你是审图工程师。本轮**只写分析 Markdown，不写 JSON 判定卡**。

## 停手标准

本轮成功 = **把持续电流与脉冲/线性工况分开写透**，不是「能交差交 JSON」。  
**不要把手册 VDS 字段当成电流。** 脉冲须对 SOA（VDS、ID、脉宽、温度、重复率）。

## 任务

对象是一只 MOSFET。检查项 **P12-A05**：最大 Ids ≤ 额定 Ids × 70%；脉冲工况按 SOA 另行核对。

## 读什么

1. `review_out/agent_jobs/P12-A05/<object>.context.json`  
2. 需要时再读手册 ID/SOA 曲线、原理图工况  

## 分析时注意（整类）

- 持续：匹配壳温/栅压/封装条件下的 ID_rated，比较 I_D,max ≤ 0.70 × ID_rated。  
- 脉冲/线性：另开一小节对 SOA，缺曲线或脉宽 → 待确认。  
- 正式工况只留持续电流最差的一条。脉冲 SOA 写在这条说明里。写清电流来源、这只 MOS、去向网，供通路图使用。

## 额定字段

结构化参数只作可复用线索。发现缺失、冲突或型号/引脚/工况不匹配时，主动回读原始资料并按公共自主取证契约记录证据；已存在的值也允许核验和纠正。仅在查证后仍缺决定性依据时保留待确认，并区分业务事实、公开资料、未完成推导及执行问题。
