# Judge · P12-A04 · 落判定卡

**名称**：MOS 管最大 Vds ≤ 额定 Vds × 70%  
**严重度**：严重

分析为主依据；本轮只压缩 JSON。缺瞬态峰值不得升「是」。

## 判据

`VDS_peak ≤ 0.70 × VDS_rated`（适用方向）。

## 落卡

`electrical`：VDS_rated / VDS_peak / limit / cite。  
- `states[]`：只保留峰值最高的一条，标 `role` 为 `worst`，并写 `why_worst`（比过启动、关断、负载里的哪几档）。
- `states[].figure`：给漏源通路图。只写名字，不写坐标。`path` 含漏端网、这只 MOS、源端网。`markers` 的 `on` 必须在 path 里。计算链用 `formula_lines`。
**是/否/待确认**均必填 `headline_zh`（见 `_common_judge`）。禁止改 `context_store`。
