# Judge · P12-A05 · 落判定卡

**名称**：MOS 管最大 Ids ≤ 额定 Ids × 70%（脉冲另查 SOA）  
**严重度**：严重

分析为主依据；本轮只压缩 JSON。持续与脉冲分列；禁止用 VDS 字段冒充 ID。

## 判据

持续 `I_D,max ≤ 0.70 × ID_rated`；脉冲/线性另满足 SOA 与热限制。

## 落卡

`electrical`：ID_rated / I_D,max / cite。  
- `states[]`：只保留持续电流最差的一条，标 `role` 为 `worst`，并写 `why_worst`。脉冲和线性区的 SOA 写在这一条的说明里，不另开一条工况。缺 SOA 证据不得对脉冲升绿。
- `states[].figure`：给电流通路图。只写名字，不写坐标。`path` 含电流来源、这只 MOS、去向网。`markers` 的 `on` 必须在 path 里。计算链用 `formula_lines`。
**是/否/待确认**均必填 `headline_zh`（见 `_common_judge`）。禁止改 `context_store`。
