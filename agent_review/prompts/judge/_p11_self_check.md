# P11 · 分析自检（同会话）

重新阅读你刚写的 `.analysis.md`，只修订分析正文（不要写 JSON）。逐项复核材料和电流平衡，不要为显得完整而新增无关工况。

## 停手标准

以「还有没有没写透的旁支 / 上界 / 路径 / 闭合」为准；**不要**以「能不能交 JSON」为准。  
完成一遍核对并修正文中的错误后结束本轮。对本轮材料无法闭合的边界，明确影响、条件和补证动作即可；不以物料缺口清零为停止条件，不反复重读同一手册或生成额外图片。

按下面**通用**问题过一遍；有问题就改正文。

最坏通路优先自检：是否比较了所有会改变对象电流的开关、钳位和接口负载状态，而非找到任意超限见证就结束？是否保留数值可算但前提待确认的最坏候选，并将其与已确认最坏分开？是否解释控制状态改变的影响方向以及未选路径为何不会更坏？若只得到一个所有互斥支路混在一起的候选连接图，必须拆成具体状态重算、分别给图。较轻对照不能替代最坏通路主展示。

1. **自相矛盾 / 假稳态**：有没有把站不住的态当成长期稳态？
2. **主依据是否物理闭合**：决定最坏应力（功耗或电压）的那一态，是否写清了「谁钉住相关电位」以及「电流从哪进、从哪出（谁灌/谁拉）」？若只用了任务书/接口的电压合法范围，却没落到钉电位与灌拉路径 → 补上闭合前提，或改以板内可自治点为主依据，或标待确认。
3. **节点电压 ≠ 对象端电压**：路径上若还有二极管、开关、其他串联件，有没有把远端节点电压直接当成对象两端电压代入？
4. **取舍是否可见**：未计入最坏应力的边界是否写明「为何不进包络」？若某旁支/指示支路被「不枚举」，是否用**一两句**交代：它有没有可解的直流平衡点、是否长期稳态、为何不抬高（或不计入）P_max/V_max？——写进正文即可，**不要**为此新开正式工况表。
5. **拓扑上界是否带条件**：若写了「两端压差不超过…」「半幅/分压上界」等，是否写清**在何种端态/忽略何种支路**下成立？勿把有条件的上界写成无条件绝对最大值。
6. **对照是否够用**：若主依据依赖外部灌/拉或接口包络，有没有至少一个更「板内」的对照量级？（有则一句即可，勿堆态。）
7. **卡点 ↔ 置信度**：分析卡点是否反映到主数字置信度？
8. **工况写法**：决定性工况及必要对照是否保留？同一路径的参数档位是否合并说明？若声称最大，是否有包络比较依据？式子是否只用材料里已有的网名和位号，没有自造缩写？每个数是否写清从哪来、怎么算？前提是否是连贯句子，而不是符号表？

无问题 → 文末可写「自检：未发现上述问题」。

支路完整性：对决定直流平衡的每个节点，从网表重新枚举所有相连引脚，与方程逐项对账，写支路审计表（引脚、直流去向、导通条件、计入项或省略依据）。不能把所有芯片脚一概称作输入漏电；按实际功能检查受控通道和其后的负载。未知控制状态说明不同状态的影响方向；漏掉的负载可能改变非线性工作点，发现后必须重算，不能只在限制段补一句。

判定充分性：按共用功耗工程判定契约检查正常设计模型或边界是否已足以判否；全局最大值、外部更重候选、全温精度的不确定性不能撤销独立工程超限。待确认须指出材料支持的正常反向情形如何改变判定，不能只列缺资料。典型模型、保证下界、保证上界和精确最大值不得混写；局部动态参数不得充当全域静态保证。不要把有出处的正常设计核算一概改成 conditional。

通路图另检：主路和影响平衡的并联支路分别给 `figure.pages[].paths`（多条路径，每条为名字数组）；兼容字段 `path` 只放主路。保留脚号，明确半导体封装内从哪脚到哪脚，禁止把并联支路串成一条线。列出源、负载和回流；跨页网只表示同名逻辑连接，不画成跨空白铜线。图中无法定位的部分必须标为未定位，不可跳过中间点后直连。

启用 basis-main.v1 时独立复核全部必要上界证明义务，尤其能量源电压包络、输入电流测试范围和长期储能条件，不能只复算数字。最终主分析、图和计算须引用正式 decision_basis；未证实候选不做主图。必要证明缺失时写 proof_gap，不以既有结论为目标。

- 对多抽头电阻链，逐个按原始网表核对两端网络，先列从电源到回地的完整链和抽头负载，再求参考电压。不得把仍串接其他电阻的抽头电阻直接当作接地支路；用节点方程或独立串并联重算交叉检查，发现前文与网表矛盾必须回改分析、计算及卡片。
