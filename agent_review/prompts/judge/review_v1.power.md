# 最大稳态功耗的极值判定

评审要求是 criterion 指定的极值约束。搜索所有影响对象电流的开关、钳位、接口端点和相容组合，不能找到任意超限数字就停止搜索。直流、长期周期、启动瞬态、故障分别建模；周期耗散使用电流有效值或波形积分，不把瞬时峰值直接当长期功耗。

先从网表逐项审计关键节点连接的器件脚、受控通道及其后负载，建立电流平衡。不要把所有 IC 脚都当高阻输入。下游节点和对象端压必须区分；对象 current、voltage_span、power 三个 metrics 均给出同一工作点核算和 calculation_ref，并满足适用的电阻关系。额定和限额用工作台材料及规则，不自己换一档。

工况分 operating_case 和 model_boundary。可用模型不等于实际可达状态：以范围外的放宽计算点作为边界时，说明放宽关系、实际范围覆盖、支路单调性及适用条件，不能只因数字超限就说是正常工况。标称工程边界用 nominal_model，不冒充全温实物 lower_bound。只有覆盖论证成立时，supported_model_boundary 才可支持判否。

对“最大值不超过上限”：有充分证据的适用超限工作点或适用边界，已能推出最大值不符合；精确最大值未知不撤销该证据。只有外部强制电位、驱动能力等未证实候选超限，仍不足以直接判否。更重候选不能丢弃，要保留数值、条件及与其他路径的比较。

主展示为最严苛可比工作状态或条件候选，不用较轻的判定边界替代主图。primary_status 区分 confirmed/conditional/unavailable。工作包络未闭合时 ranking_complete=false、global_value=null；不能以任一候选填成全局极值。

待确认必须有材料支持、可能改变判定的反向情形；仅影响更重候选或精度的缺口不覆盖独立充分证据。符合需要完整覆盖的正确方向包络界，不能只因已列工况都未超限而通过。若使用 bound，metrics.nature 必须说明方向；上界超过限额不等于实际必然超限。

判定正文围绕极值要求，说明主候选、限额及证据边界；不把“只评普通情况”作为理由。通用方法不得写入特定位号、板名、预期功耗或目标 verdict。
