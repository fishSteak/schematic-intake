# DS_ORI、SIG_ORI：电平检查语义与可复用独立模型

日期：2026-10-22。仅原材料、准确厂家手册与规则语义复核；未改正式卡或代码。

## 1. 必须分开的三种问题

`rules/product_center_15.json`将P12-A02定义为“发送端VOH/VOL与接收端VIH/VIL在全工况下兼容”，P21-A01为“发送端输出电平与接收端VIH/VIL阈值兼容”；后者对象备注限定两颗及以上IC的信号网，两项共享阈值证据。

因此应区分：

1. **数字逻辑阈值兼容**：驱动器保证VOH/VOL、接收器保证VIH/VIL及实际负载；适合真正逻辑控制路径。
2. **模拟功能/输出量程**：跟随器是否输出0～10V、比较器是否跨过设计参考；不能给模拟运放凭空造VIH/VIL。
3. **模拟输入推荐范围/绝对最大**：运放共模、模拟开关信号端VSS～VDD、输入损伤边界；不能把“未损坏”当功能保证，也不能把模拟输入不满足推荐范围写成数字阈值不兼容。

DS_ORI、SIG_ORI虽连接多颗IC，实质都是模拟网，不能因多IC就强行填VOH/VIH数字模板。若主流程约定P12-A02/P21-A01同时承载模拟输入适配，应明确使用模拟范围子模型；若严格限定数字IO，则这两网数字阈值子项不适用，模拟功能/输入范围风险应移交对应检查，不能泛写“缺VIH所以待确认”。

## 2. 任务书确认的边界

原始`material_inputs/design_task_book.yaml`及DOCX 2026-10-09增补：CN1.SPDL为板输入0～10V；CN2.SIG、DS为板输出0～10V，正常外接高阻/开路；+24V/+12V本轮按标称。`operating_conditions.yaml`已confirmed；CN2的对地短路故障不参与正常工况。

“高阻”使R18/R19在正常DC没有显著压降，并减轻U4输出负载；它不能给DS_ORI/SIG_ORI增加10V钳位，也不表示内部R34、R35反馈或U5负载消失。外部输出0～10V是需求，不能直接倒写成已经实现的内部电压保证。

SPDL的源阻抗、吸流能力未统一限定。若选择理想/低阻0～10V外部源，可作为明确允许条件模型；若选择弱源或开路，必须检查是否仍符合SPDL端0～10V条件，不能用一个最后使SPDL本身升到11V的模型冒充已确认10V输入工况。

## 3. DS_ORI：实际驱动、负载、接收端

原始网表及PDF：第9页P08为上游，第4页P03为U5负载，第5页P04为检测，第3页P02为缓冲/交流耦合。

| 端口/支路 | 角色及供电 | 实际性质 |
|---|---|---|
| +24V→R4/R52/R47/R46→D8.3→D8.1 | 480Ω串阻供能，D8为永裕泰MMBD4148CA | DS_ORI是二极管供电/限流网络，不是某逻辑IC主动高电平输出 |
| D8.2→SPDL，D9、Q4 | 另一分流支路/输入与下拉 | 外部SPDL源及Q4状态会分流供电，影响DS_ORI |

| U5.1/3/9/11 | CD4066信号端，供电12V；另一端各经3.9k到地 | 四个控制脚固定12V，正常全开；不是DS_ORI数字逻辑输入 |
| U2.2 | LM393DR反相输入，供电VCC24V | 比较模拟电压与U2.3约7.05V参考 |
| U4.3 | LM358BIDR同相输入，供电VCC24V | 跟随缓冲至U4.1→R19→CN2.DS |

### DS供电节点方程

令a=N_DS_FEED、v=DS_ORI、p=SPDL，D8两支电流为ID、IP：

`(24−a)/480 = ID(a−v)+IP(a−p)`；
`CΣ v' = ID − IZ(v,T) − Σ[v/(3.9k+Ron)] − (v−x)/10k − Iinputs`。

这是实际电压来源。忽略SPDL分流、D10正常调节时v约11V，不能因此说所有正常输入下都恒为11V。SPDL低阻0V会把a拉低，DS_ORI也随之降低；SPDL低阻10V时，应同时解D8两结不同负载电流的VF，不能直接把p=10推出v≤10的硬保证。

上游弱分流状态下11V是明确内部候选量级；若要用它作为“正常外部DS输出超过10V”的失败见证，必须同时给出SPDL端状态，使它仍符合0～10V输入规格。仅把SPDL开路并让其被D8充至11V，不能自动称已确认正常输入见证。这个一致性条件应保留，不能因D10标称11V就跳过。

### DS到外部DS的关系

正常跟随器线性、高阻输出时

`V(CN2.DS)≈v+Vos(U4)`，`I_R19,DC≈0`。

所以R19不会把11V降成10V，24V供电的U4也不会因为输出需求为10V就自行在10V限幅。实际v如果正常达到>10V并超过允许输出误差，就会形成模拟量程冲突；这是需求/模拟输出问题，不是数字VIH/VIL问题。

U4共模上限按全温推荐约VCC24V−2V，正常0～约12V输入远低于约21V；因此不应把“DS高于10V”误判为U4输入过压或共模超限。

## 4. SIG_ORI：实际驱动、反馈、比较和外部缓冲

原图第7页P06为源，第6页P05为阈值，第3页P02为外部缓冲。

| 端口/支路 | 角色及供电 | 必须比较的量 |
|---|---|---|
| U7.7 | LM392MX/NOPB运放输出，12V供电 | 模拟闭环输出范围/负载/饱和恢复，不是数字VOH |
| R34=10k到地 | 恒定输出负载 | 不能被外部高阻条款删掉 |
| R38+R35与C11 | 到U7.6负反馈 | 反馈增益、频响、输入钳位可能性 |
| U4.5 | LM358BIDR同相端，VCC24V供电 | 模拟共模及跟随输出精度；U4.7→R18→CN2.SIG |
| U7.2、U7.3=LEVEL1 | LM392内另一比较器，12V供电 | SIG_ORI与LEVEL1的比较及共模条件 |
| U3.4/6/8/10，其他端LEVEL2～5 | LM339DR四个比较器，12V供电 | 模拟比较阈值及适用共模，不能调用CMOS VIH |

令s=SIG_ORI、n=DS_DELAY、x=N_U4_FILTER，r=R38、Rf=10k+r，参考b0≈5.1724V。

正常线性、小信号/低于C11反馈拐点时：

`n≈b0`；
`H_xD(p)=[k pτ9/(1+pτ9)]/[1+p Rt C7+ p Rt C9/(1+pτ9)]`，其中k=2/3、Rt=R21||R20、τ9=R22 C9；

更直接的节点式是：

`(v−x)/R21−x/R20−C7 x'−i9=0`；
`C9(x−b)'=(b−n)/R22=i9`；
`(n−s)/Rf+C11(n−s)'−i9−jinput=0`。

不能只写“输入0～10所以s0～10”，因为此链路包含交流耦合、反馈增益和饱和。直流C9隔断，s≈n≈5.172V；周期输出摆幅随v的交流分量、R38和频率变化，并可能饱和。U7输出摆幅表约0～V+−1.5V是特定负载/25℃参数，不是任意频率、外灌电流下的硬钳位。准确资料不支持无条件“内部SIG永不超过10V”。

正常U4跟随且外部高阻时，`CN2.SIG≈s+Vos`。R18=2k不提供10V限幅。若正常s实际超10V，需要归入模拟输出量程核对；若s不足以跨某级参考，则属于分级功能覆盖问题。

## 5. 参考阈值：计算值而非数字输入规格

+12V经R23(3.3k)、R24(2.7k)、R25(2.7k)、R26(2k)、R27(1.5k)、R37(1k)、R36(10k)到地，总23.2k。忽略输入偏置的标称阈值：

| 节点 | 标称电压 | 接收比较器 |
|---|---:|---|
| U7参考N_U7_REF | 5.1724V | U7运放同相端 |
| LEVEL1 | 5.6897V | U7.3，SIG_ORI接U7.2 |
| LEVEL2 | 6.4655V | U3.7，SIG接U3.6 |
| LEVEL3 | 7.5000V | U3.11，SIG接U3.10 |
| LEVEL4 | 8.8966V | U3.9，SIG接U3.8 |
| LEVEL5 | 10.2931V | U3.5，SIG接U3.4 |

上升SIG超过各参考时，相应开集电极比较器趋向拉低（须遵守共模/过驱动条件），但这些模拟参考不是厂家VIH/VIL。最高级参考10.293V高于外部SIG声明上限10V：如果设计要求0～10V内五级全部可达，则构成功能矛盾候选；原始任务书尚未给出每级必须可达的详细动作规范，不能直接假定这个设计意图后判失败。

## 6. 准确接收器推荐范围及容易混淆的例外

- **U4 LM358BIDR**：TI SLOS068AB，缓存准确厂家PDF第5页推荐共模V−～V+−2V，第6页B版参数，供电VCC24V。其输入绝对最大上限40V（第4页）与线性共模上限不同，二者都不是0～10V输出需求。
- **U2 LM393DR**：TI SLCS005AH，第8页非B LM393参数：正常共模0～VCC−2V全温；注释允许一端超共模，只要另一端在有效范围内即可给正确比较状态（且不超过适用输入范围）。本板参考约7.05V处于VCC24V有效范围，不能仅因DS_ORI约11V就说U2过共模。
- **U3 LM339DR**：TI SLCS006Z，第10页非B/非A参数：全温共模0～VCC−2V，本板12V时为0～10V；25℃约0～10.5V。页下注释明确：一端可超VCC，只要另一端仍在共模区即保持正确比较；输入损伤限值另列。不能机械要求两个比较输入每个时刻都≤10V而完全忽略该例外，也不能把这个例外扩大为两端都超共模仍保证。
- **U7比较器**：准确LM392-N SNOSBT5D第3～4页，同样存在比较器一端保持共模时的高端输入例外；**其运放输入不应超供电**，不能把比较器例外推广给U7.6运放端。
- **U5 CD4066BM96**：TI SCHS051J第4页，模拟信号端推荐VSS～VDD，即本板0～12V；绝对最大VSS−0.5～VDD+0.5只是损伤边界。U5的VIHC/VILC针对控制脚，本板控制脚直接固定+12V，DS_ORI接的是模拟通道，不能拿0.7VDD当它的数字阈值。

最高级LEVEL5=10.293V在25℃U3共模10.5V内，但已高于全温保证上限10V。如果SIG也超过10V，则最高级比较器两端可能同时在全温共模范围之外，前述“一端有效”例外不再自动适用。其他LEVEL2～4仍低于10V，可为同网不同接收器分别保留比较保证。故必须逐接收端审查，不能对整个SIG_ORI网写一个统一共模结果。这个问题与“SIG输出必须0～10V”是两个不同检查口径。

## 7. 已有充分关系与真实未闭合点

| 关系 | 已有充分事实/模型 | 真正剩余问题 |
|---|---|---|
| DS_ORI→U4→CN2.DS | U4跟随，输出高阻时R19无显著DC降压，需求0～10V不构成钳位 | 合法SPDL源/状态下的实际DS最大值与输出允许误差；11V候选见证需保持SPDL输入规格一致 |
| DS_ORI→U2 | 阈值约7.05V，参考在供电共模内 | 具体动作规范/动态边界，不是缺数字VIH |
| DS_ORI→U5模拟端 | 正常12V供电，推荐模拟范围0～12V，四路控制固定高 | D10温漂/启动时+12V未建立等是否越过模拟范围；不使用abs-max充当钳位 |
| SIG_ORI→U4→CN2.SIG | 高阻跟随，R18不衰减；源为U7模拟反馈链路 | 正常交流幅频/调整状态能否满足0～10V需求；不能由需求反推源硬限幅 |
| SIG_ORI→U7/U3各比较器 | 已计算各参考及明确共模例外 | LEVEL5全温双输入超共模候选；级别可达性是否属于功能要求 |
| 两网数字阈值子项 | 网本身为模拟路径 | 应选择模拟适配模型或标明数字子项不适用，不伪造VOH/VIH字段 |

本轮标称供电已确认，不应把上述问题统一变成“请补电源上下限/纹波”。也不应因尚未得到精确波形最大值而删掉明确参考值、跟随关系、最高级共模候选。边界需要针对具体接收器和具体功能定义。
