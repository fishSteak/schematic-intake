# R4、R16 / P11-A01 独立复核

日期：2026-10-22。仅独立材料复核、厂家PDF读取和计算；未改正式卡、提示词或代码。

## 结论

**R4存在正常允许输入端点下的明确工程超限见证，应判功耗不满足，不能因精确全局最大尚未知撤销。R16具有充分低于50mW的覆盖，可判通过。** 两者均为厚声0603WAF系列0.1W，当前50%线为50mW。

R4在正常SPDL=0V、低输出阻抗传感器/校验源条件下，经D8形成连续约48mA供电回路，每颗120Ω约0.28W。0V是已确认正常输入量程端点，不是CN2输出短路故障。该见证明确要求源能吸收该电流，不能描述为所有传感器必然发生；任务书没有排除这种正常低阻0V输入，因此它是允许集合内的设计见证。另有不依赖外部端点吸流的正常DS_ORI≈11V稳压工作见证，R4约79mW，亦超过50mW。

R16只在POW_TECH和C5/U2.6间，300kΩ大电阻使0～24V工程摆幅下任意瞬时功率≤1.92mW；正常稳定DC只有输入偏置电流，周期振荡模型约0.4mW。C5充放电不能被忽略，但不会填平至50mW的数量级裕量。

## 2. R4：允许端点见证与真实连续回路

### 2.1 正常SPDL=0V的低阻输入见证

选择一个任务书允许的外部源：0V、可吸收约50mA的低阻传感器输出或校验源。它未被当前接口规格的源阻抗或限流条款禁止。回路为：

`+24V → R4 → R52 → R47 → R46 → D8(3→2) → CN1.SPDL的0V源 → GND → 24V电源回路`。

令a=N_DS_FEED，VF为D8的实际正向压降：

`Iseries=(24−a)/480=(24−VSPDL−VF)/480`；
`P_R4=120 Iseries²`。

在VSPDL=0V、VF≈0.8V典型见证下：I≈48.33mA，P_R4≈280.3mW，是50mW线的5.61倍，也超过0.1W额定。即使故意取VF=2V，仍有252.1mW。VF=2V不是厂家保证值，而是检验结论敏感性的宽工程取值。

更清楚的阈值：Icrit=sqrt(0.05/120)=20.412mA；对应允许的串链压降仅9.798V，因此若a<14.202V就已经超50mW。0V输入情况下要推翻这个超限见证，须让健康的4148正向压降达到14.2V量级，或让所选0V源无法吸收电流而离开该电压状态。前者与厂家准确正向特性严重不符；后者是换了外部源模型，不能否定另一个允许的低阻源见证。

取四电阻±1%使R4功率最小的组合：R4=118.8Ω，其他三只121.2Ω，总482.4Ω；0V/VF=0.8V时P≈274.8mW，仍远超50mW。无需再求某个器差组合的精确全局最大。

**见证性质：** 此处0V源吸流能力是见证的显式条件，不是假称所有实际传感器都有50mA能力。当前正常输入量程允许0V，且未限定外部源阻抗，故选择健康低阻源属于允许运行集合，而非任意把SPDL短路故障塞进模型。如果项目以后明确源端限流/高阻规范，才需要重新限定见证域；当前不应先要求用户补料才能承认这条已存在的工程风险。

### 2.2 不依赖外部源强吸流的第二个正常DC见证

取SPDL=10V、高阻/有限驱动，DS_ORI由板内D10维持约11V。N_DS_FEED仍可经D8向DS_ORI、U5负载和D10供电；若SPDL支路也吸流，它只会把a拉得更低，增加串阻电流。

先取正常健康器件典型a≈11+0.7=11.7V：I≈25.625mA，R4≈78.80mW，超过50mW但尚未超过0.1W原始额定。参考D10准确先科PDF第2页11V/20mA测试点及D8第2页典型正向曲线，这是合法的正常工程工作点见证；不是在宣称D10全温最大都恰为11V。

即使D10取25℃测试点上限11.55V、D8工程估算1.0V，a=12.55V，I≈23.85mA，R4≈68.28mW，仍超50mW。D8的1.0V在该电流不是表格保证，所以这行属于敏感性工程核算，不应改写成完整厂家最坏保证。

这个正常DC见证已经足以支持P11-A01不满足，无需让“启动时+12V是否先建立”“精确振荡占空比”否定它。高温D10包络可能使该特定工况裕量变小，并不使25℃允许工况消失；最大值检查只需存在一个允许工况超线。

### 2.3 周期电流、平均功率与单次启动

若N_DS_FEED在a_L/a_H间周期变化，稳态热平均是

`Pavg=120×[D(24−a_L)²+(1−D)(24−a_H)²]/480²`。

不能用平均电流平方代替均方电流。在0V输入长期保持的见证D=1，本身就是连续稳态，不需要占空比；在“低态0.8V、高态11.7V”示例中，两个状态分别约280mW与79mW，都超过50mW，任意占空比均超限。若选到一个低于50mW的高态，再解D临界即可，不能默认它稀少到可忽略。

单次上电时C17/C18充电可使串阻电流短时接近24/480=50mA，每颗峰值300mW；这条需要脉冲持续时间和电阻脉冲规范，不能冒充持续功耗结论。但本项已有独立持续工况见证，故不依赖此启动峰值来判不满足。

## 3. R16：C5反馈滤波/振荡回路，不是恒流供电电阻

原始连接：R16.1=POW_TECH，R16.2=N_U2_FILTER；C5从N_U2_FILTER对地，U2.6接该节点；U2.1和U2.7开集电极输出同接POW_TECH。R14从POW_TECH到N_U2_REF24；R15从VCC24V到该参考；R13从参考到地，均100k。

令o=POW_TECH、z=N_U2_FILTER、h=N_U2_REF24、E=VCC24V：

`h=(E+o)/3`（忽略微小输入偏置）；
`C5 dz/dt=(o−z)/R16+i_b`；
`P_R16=(o−z)²/R16`。

R2/LED1.G构成o的上拉通路，R15/R14/R13也是弱偏置/反馈通路；U2的开集电极只能拉低，不能当一个主动24V电压源重复串入R16。比较器1阈值12×47/(33+47)=7.05V；DS_ORI>7.05V时它把共享o拉低，第二比较器不能独立输出高态。因此“R16必然始终振荡”也不成立。

### 3.1 长期DC

o被某比较器长期拉低或保持不变后，C5无DC电流，R16电流只补偿U2.6偏置。按400nA量级，P≈(400nA)²×300k=48nW。该表格偏置值须按正常输入范围解释，不外推负向钳位；本回路正常z非负且在供电范围内，无需要负电压才能工作的机制。

### 3.2 允许振荡与周期平均

当DS_ORI降低、比较器1释放，共享o可由LED/R2及电阻网络上拉，比较器2通过R16/C5和R14形成迟滞振荡。若高低电平为H、L且近似稳定，阈值为A=(E+L)/3、B=(E+H)/3，需满足L<A<B<H。

令τ=R16C5=0.3s：

`t_H=τ ln[(H−A)/(H−B)]`；
`t_L=τ ln[(B−L)/(A−L)]`；
`Ecycle=(C5/2)[(H−A)²−(H−B)²+(B−L)²−(A−L)²]`；
`Pavg=Ecycle/(t_H+t_L)`。

取一个仅用于数量级的示例E=23.3V、H=22.3V、L=0.2V（D2/LED压降和集电极饱和电压为工程典型，而非业务新增条件）：A=7.833V，B=15.2V，tH=0.2135s，tL=0.2027s，Ecycle=162.8µJ，Pavg≈0.391mW。真实LED I-V使高电平随z变化，此简化不是精确频率/全局最大；不影响下一条更宽覆盖。

### 3.3 足以判定的覆盖

对正常单电源、无外部强驱动o的0～24V工程范围，一阶C5状态z是o历史的加权平均，因此z也在0～24V；任意周期、任意占空比均有

`|o−z|≤24V`，`P_R16≤24²/300k=1.92mW`。

即使取R16下偏1%=297k，覆盖仅1.939mW，约50mW线的3.88%。反算必须有持续/重复的R16端差达到sqrt(0.05×297k)=121.86V才能触线。本板没有这种正常源，LM393输入偏置及LED/电源典型压降也不可能提供100V级增量。此为有明确回路来源的工程覆盖，不是拿开集电极绝对最大值当动态钳位保证。

C5的单次初始充电能量不需要为P11-A01最大稳态额外生成未确认业务输入；如果检查异常外部预充电或过压，另做脉冲/故障分析。

## 5. 判定边界

| 对象/证据 | 当前正常最大稳态范围是否足够 | 缺口是否撤销结论 |
|---|---|---|
| R4，SPDL=0V低阻源持续见证 | 是，正常量程允许端点；显式给出吸流条件 | 传感器未统一规定源阻抗不等于禁止该允许源；应保留条件，不能假装普遍必然 |
| R4，DS_ORI≈11V正常稳压见证 | 是，约79mW>50mW | 精确全温最大/启动波形未知不撤销25℃正常超限见证 |
| R16，完整24V端差宽覆盖 | 是，≤1.94mW | 不需要精确振荡频率/LED高电平/占空比才能通过 |
| 任意故障、EMC、任意预充电 | 不属于上述正常核算 | 不偷换为当前工况，也不签发其全状态保证 |
