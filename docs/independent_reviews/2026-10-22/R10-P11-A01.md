# R10 / P11-A01 独立复核

日期：2026-10-22；只分析，不修改正式结果或代码。

## 结论

R10是Q3的30Ω发射极串联电阻，不是R9/Q2的基极下拉电阻。正常小负载下功耗很小，Q3导通电流受“D4双结钳位减去Q3实际VEB”形成负反馈限制，不能直接用24²/30判超限，也不能用固定0.7²/30就宣称全部工况通过。

已有原材料足以建立明确负载线和很窄的结论阈值：**若在R10电流约40.6～41.0mA处，Q3实际VEB至少约0.49V，则按准确AnBon D4在10mA的最大正向压降可封住50mW线。** 实际D4电流受R9限制在约1.21mA以下，其典型正向压降更小，正常工程工作点约数mW至十余mW，因此没有已成立的R10超限见证。

但本次找到的本地S9015手册是错误TO-92/450mW版本，并非BOM的Doeshare SOT-23，不能据它完成Q3全温VEB下界保证。仅用所有已核对的最大参数、完全不使用Q3正向VEB下界，所得保守上界约98mW，跨过50mW，故**这个松上界不能证明通过，也不能证明不满足**。最小技术缺口是准确Q3在临界电流/温度下的VEB下界或直接负载线验证，而不是整张逐点VBE曲线，也不是把外部负载全套业务规格重新索取一遍。

## 2. 精确静态负载线

令U=N_Q3_SUPPLY、B=Q3基极、E=Q3发射极、C=OUT_ORI、Q=OUT_LED（Q2集电极）。取正方向PNP发射极电流IE、基极外流IB、D4串联电流ID。

`VR10=U−E=30 IE`；
`VEB=E−B`；
`D=U−B=VR10+VEB`；
`D=VD4a(ID,T)+VD4b(ID,T)`（D4正向导通时）；
`(B−Q)/R9 = D/R6 + ID + IB`。

因此

`ID=(U−D−Q)/R9−D/R6−IB`。

正常正向导通IB≥0、Q≥0，故

`0≤ID≤U/R9≤24/19.8k=1.212mA`。

这条约束来自真实基极下拉源阻抗，与外部集电极负载大小无关；不能把D4任意放到10mA或50mA而不检查R9供流。D4中两只结是串联同一电流，不是每只各灌一半。

健康硅结正向I-V单调，则25℃下ID<10mA可使用准确手册的10mA最大值作宽上界：

`D≤2×0.855=1.710V`。

所以

`VR10≤1.710−VEB`，`P_R10≤(1.710−VEB)²/R10`。

若完全只取VEB≥0，则R10下偏1%=29.7Ω时上界约98.45mW。这是因完全删去Q3正向结压降而得到的**过宽覆盖**，不是实际超限点。不能用它判失败。

在50mW边界，R10=29.7Ω时VRcrit=sqrt(0.05×29.7)=1.2186V，IEcrit≈41.03mA；R10=30.3Ω时VRcrit=1.2309V、IEcrit≈40.62mA。要由D≤1.710V封住全容差边界，只需Q3在该电流处具有VEB≥0.4914V（最保守一端）。不需要完整逐点曲线，取得这个单侧技术保证或验证就足够。

注意D4表格是25℃，不能不声明温度就把1.710V写成全0～70℃/自热厂家保证。厂家100℃典型曲线显示升温通常降低正向电压，但不同器件、不同温度的匹配并未由该曲线保证；准确全温证明须按实际D4/Q3温度组合核查。该温度问题是技术证据范围，不是要求业务重复批准标称供电。

## 3. Q2驱动与正常状态

OUT_N为U6.6、12V系统输出。即使其高电平取12V，也有R8=20k串联。用Q2正向压降0.7V作数量级示例，IB2≈(12−0.7)/20k=0.565mA。实际值应由U6带载输出特性和Q2结压降决定，不能将该示例当保证。

Q2只需吸收经R9约1.2mA，以及LED1.F/R53约毫安量级；其正常低态有充分驱动量级，故可以建立Q2拉低的工程工况。但Q2手册100mA/10mA测试点不能直接冒充此基极电流下的饱和保证。更关键的是，**若Q2拉不够低，Q会上升，ID和Q3基极驱动都会降低，R10电流不会因此变得更大**。因此进行R10上界时，取Q=0是保守负载线边界，不需要先证明Q2一定达到恰好0.2V。

Q2关断时，R6将Q3基极拉回供电，Q3截止，R10只余漏电；OUT_ORI由R5=20k回地。Q2导通时，基极下拉和D4钳位使Q3打开，R10对IE形成局部负反馈。Q3基极电流由实际负载/β要求，不是凭VBE=0.7V凭空指定电流。

H1若连NPN脚与OUT_ORI，会把Q1集电极接入输出；Q1与Q2受同一OUT_N驱动，因而可能形成Q3供电与Q1下拉同时存在的负载。不能忽略这条候选路径，也不能在H1未定义时擅自宣称其必接。上述D4/R9负载线的目的正是尽量不依赖具体外部负载。

## 4. 已有工程工作点与不能升级的结论

### 小负载状态

若数字输出外部开路且H1不引入Q1下拉，内部R5=20k及CN2.OUT经R17=10k后的高阻负载仅需约毫安电流。IE≈1.2mA量级，P_R10≈43µW。这里只是一个明确条件下的正常低功耗见证，不证明所有数字负载均小。

### 钳位限流状态

D4约1mA时，其两结典型总压降约1.2～1.4V；Q3在数十mA时实际VEB通常约0.65～0.85V。以D=1.3V、VEB=0.75V作为明确工程工作点，VR10=0.55V，IE=18.33mA，P=10.08mW；基极节点须满足上面的R9/R6/IB方程，不能把这两个压降当可任意独立选择的保证参数。此例解释原设计为何使用两个钳位结配一个发射结加30Ω限流。

若误把“D4两结各0.7V、Q3一结0.7V”写成固定关系，则得到16.3mW；这个数可以作典型数量级，不能作50%功率保证。相反，删掉VEB然后用1.71²/30≈97.5mW判超限也不成立，因为根本没有展示Q3在40mA处能有接近0V的正向VEB。

准确资料目前既没有证明临界电流处VEB足够低而产生超限见证，也没有取得全温≥0.491V下界。应将缺口缩到这个临界负载线条件，而非笼统“没有逐点VBE曲线所以完全无法分析”。

## 5. 正常周期和单次边沿

周期平均为`Pavg=R10 <IE²>`。如果已证明每个正常持续导通状态的IE上界，则任意占空比的周期平均自动被该上界覆盖，不需要再求精确频率。如果只有某个占空比下的平均值，则不能把它当瞬时或长持续高态保证。

本支路没有显式电容直接跨R10或Q3基极；U6周期驱动、BJT存储电荷和外部负载电容可引入边沿电流。它们属于必要时的瞬态/重复脉冲补充，不应凭未给寄生电容就否定静态负载线，也不能声称静态上界自动覆盖所有电容负载尖峰。

若未来实测发现某正常持续高态IE>40.8mA，则R10已有直接超50mW见证；若只出现短边沿，则必须结合占空比、均方积分及电阻脉冲能力，不能直接把峰值I²R冒充最大稳态功耗。
