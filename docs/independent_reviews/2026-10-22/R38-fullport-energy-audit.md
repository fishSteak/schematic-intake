# R38全端口增量储能：不以实际节点硬钳在电源轨内为前提的尝试

日期：2026-10-22。独立技术推导，不修改已交模型的文档、正式卡、原材料或程序，不运行CLI。

## 结论

得到一个新的**有明确端口条件的充分平均功耗证明**：将DS供电/负载前端与U7输出级一起纳入储能，实际DS_ORI、N_U4_FILTER、SIG_ORI都不必逐点满足原来的24V/12V硬边界。真正需要的是两个正常电路端口的增量被动/耗散模型，以及对额外主动输入电流的功率预算。

在这些正常工程端口条件下，先不计微小有源输入电流，固定电阻±1%保守预算约7.273mW，对R38给出`I_rms≤约0.858mA`，局部50%热限额最保守比例约0.324；全阻段总平均功率宽界约6.68mW。这里比较的是**局部阻段平均热负荷**，不是把全板0.3W粗功率当成R38功率，也不是峰值/触点脉冲认证。

但是，准确LM392-N手册没有给出“任意输入过驱动、任意内部寄生状态均满足下述耗散不等式”的认证；CD4066等完整前端的任意越轨增量I-V也未由厂家保证。因此本文件给出的是可审计的正常工程模型及其充分结论，**尚未完成无条件全动态厂保式证明**。它将真实余项从“必须先求每个端口最大电压”改成“这些具体正常端口能否按所列物理模型使用/验证”，不能直接将假设写为厂家事实。

- v接C17/C18到地、D10到地、U5的四个模拟支路及R21。U5四个控制脚接+12V，四个另一信号端分别经R39～R42=3.9k到地；正常功能为四路常开下拉。

## 2. DS前端：界定开路参考源，而不是界定实际被回灌节点

在C9接口x处，将整个DS供电、D8/D9/D10、U5负载、R21/R20、C7、C17/C18作为前端F。端口电流i由x流向C9/R22。选择**与实际前端具有相同24V供电、相同SPDL波形和控制状态，但C9端口电流为零**的参考轨迹，记其x电压为ex(t)。这只是分析参考，不是另一个实际工况，也不把参考电压移植为实际x的硬上界。

对于正电阻、接地电容、单调二极管及正常闭合的被动模拟开关支路，实际轨迹与参考轨迹的差储能SF满足增量端口不等式

`SF' ≤ (ex-x) i + PF_active`。

推导要点：两轨迹的独立源电压完全相同，增量边界源功率为零；电容采用差电压平方储能；每个单调电阻/二极管有`(va-vb)(ia-ib)≥0`，所以只剩端口负功率`-(x-ex)i`与另外明确列出的有源偏流项。有限正值的C18大小影响轨迹，但不影响此周期平均结构，不需为该式猜测TBD电容值。

开路参考侧已去掉来自U7/C9的回灌，剩余储能是接地电容。正常零/正常供电历史、无外部过压注入时，最高驱动源为24V；SPDL实际0～10V分流支路、正常12V保护/控制端均不提供高于24V的独立源。在上述正常被动模型内，参考v不超过24V；参考x满足明确的一阶方程

`C7 ex'=(v_ref-ex)/R21-ex/R20`。

因此`0≤ex≤24 R20/(R21+R20)`。按R21下偏1%、R20上偏1%，宽取`ex≤16.107V`。**被限定的是解除C9负载后的参考源ex；实际v和x即使被C9暂时推过该界，也不破坏增量储能式。** 这正是与旧“实际DS_ORI硬≤24V”的区别。

适用边界须保留：真实U5支路的正常闭合被动/单调I-V是工程模型；若进入未建模的主动保护、寄生供能或失电反灌状态，需计入PF_active。不能仅因器件叫模拟开关就宣称厂家对任意越轨都保证该增量不等式。

参考轨迹使用前端的被动骨架；U2/U4等普通有源输入电流不参与该参考源上界，而在实际相对参考的供能PF_active中保留。PF_active指其**增量功率项**（相应节点差电压乘额外电流），不是IC整机供电功率。没有这项区分，就不能既把参考源视为纯被动，又默默保留会向它主动灌电的输入源。

## 3. U7输出：允许端口越轨吸能的耗散模型

记Io为U7输出级向u节点送出的电流。正常由0/12V供电轨控制的输出级可使用如下工程模型：存在内部控制源`0≤e(t)≤12V`与非负端口相关储能SU，使

`SU' ≤ (e-u) Io`。

有非负输出电阻ρ时，`u=e-ρIo`直接给出右端`ρIo²≥0`；更一般情形允许越轨能量由内部电容释放/吸收并计入SU。**该模型没有要求实际u∈[0,12]，也没有用输出摆幅表冒充硬钳位。** u>12V且外部向IC灌电、或u<0V时输出回收的状态可以纳入。准确第5页上拉/下拉拓扑为这个正常输出工程模型提供来源。

这仍是一项模型条件，而非TI对所有寄生过驱动给出的现成保证。**不能把全部内部Cc储能并入SU，却不记内部偏置源给Cc充电的功率**：即使外端Io=0，内部状态也可能从电源获得能量。这里SU只可表示已建立端口能量关系的那部分电荷；内部Cc主要作用于控制e，其直接寄生耦合/额外供能若不能由该端口模型覆盖，应另加PU_extra。正常周期储能SU收支平衡，并不单独证明PU_extra平均为零。若内部寄生能够从电源主动向越轨端口泵能，不能在这里悄悄忽略。

## 4. 合并后的能量式

定义`w=x-b`、`d=n-u`、`I38=d/f`。C9支路电流i由x经C9、R22流向n。输入端向n注入电流j，拆成正常负向接地结jc与普通/额外有源输入jb。u处其他接收输入的总吸收电流记IL（允许有符号）。准确节点关系是

`C9 w'=i`；`C11 d'=i-d/f+j`；

`Io=u/R34-i-j+IL`。

耦合/反馈储能`SC=(C9 w²+C11 d²)/2`满足

`SC'=(x-u)i-a i²-d²/f+d j`。

加上前端SF及输出SU，并代入输出节点KCL，得到

`E' ≤ (ex-e)i-a i²-f I38² + (e u-u²)/R34 + (n-e)j + (e-u)IL + PF_active + PU_extra`。

这一步是关键：负向接地钳位jc≥0只在n<0时产生，而e≥0，所以`(n-e)jc≤0`。**不再要求实际u≥0，也不需要给jc精确电流或固定-0.3V夹位值。** 输入寄生改变输出控制时已通过e与SU进入；额外主动供能则必须放进相应项。

先忽略微小jb/IL及另列有源项，完成平方：

`(ex-e)i-a i²≤(ex-e)²/(4a)`；

`(e u-u²)/R34≤e²/(4R34)`。

正常周期平均E'=0，于是

`f <I38²> ≤ max[(ex-e)²/(4a)+e²/(4R34)]`。

对`ex∈[0,16.107]`、`e∈[0,12]`，右式为凸二次式，最大值在矩形四角，不是扫描猜测。a、R34保守取9.9k：

- ex=0、e=12：约7.273mW；
- ex=16.107、e=0：约6.552mW；
- ex=16.107、e=12：约4.063mW；
- ex=e=0：0。

所以充分预算为7.273mW。f≥9.9k给出`I_rms≤sqrt(7.273mW/9.9k)=约0.858mA`。TR≤110k时，50%局部功率等效电流为sqrt(0.25/110k)=1.508mA，因此全在用段范围的最保守热负荷比例约`(0.858/1.508)²=0.324`。总阻段平均功率`P38=r<I²>≤7.273mW*r/(R35+r)`，r≤110k时约≤6.68mW。

这些是充分覆盖，**不是声称存在某个实际工况同时取到所有角点最大值**。不应用一张真实电流通路图把跨波形完成平方关系画成实际同时导通状态。

## 5. 输入偏流及额外主动供能的容限

普通输入jb与其他输出接收输入IL不能简单删除。令`h=jb-IL`，合并它们的u相关项后，出现

`(e u-u²)/R34+(u-e)h+d jb`。

若相应正常工作区能给`|jb|≤J`、`|h|≤H`，则对u完成平方可得附加宽预算

`≤e²/(4R34)+12H/2+R34 H²/4+f I_rms J`。

以H=10µA仅作敏感性示例，前两项之外只增加约60.25µW；不是宣称已从所有输入手册取得这个联合保证。准确U7普通偏流400nA在适用区增加量也很小；但不能用该表覆盖所有输入保护导通。

局部50%允许功率对应的最小支路预算为`9.9k*(0.25/110k)=22.5mW`，相对于7.273mW尚有约15.2mW差额，可用于明确计入额外主动输入/寄生供能。这个余量说明根本不必求纳伏级精确节点最大值；但未给出的PF_active、PU_extra不能凭“通常很小”直接写零，更不能把IC整机静态功耗直接全部加进R38。

## 6. 哪些已完成，哪些未完成

**已完成的推导：** 真实前端/输出/耦合拓扑下的统一储能关系；去掉对实际DS_ORI、x、u逐点电源轨硬界的依赖；负向接地钳位项非正；正常耗散端口模型下的矩形角点平均功耗充分界；微小及额外主动端口的独立预算位置。全板输入功率没有被粗分配给R38。

**未完成的严格厂家保证：** TI手册没有给任意内部寄生/过驱动状态的SU耗散认证；真实U5和输入保护全越轨增量I-V未逐一验证；其他接收输入在全部越轨状态的联合主动功率未取得硬上界。准确第5页拓扑及正常电路物理支持工程模型，但不等于厂家逐状态保证。单次任意预充电初值、全部脉冲/滑臂峰值也不由周期平均E'=0证明。

因此主流程可基于本轮“正常标称周期工程核算”的明确口径采用该模型作为充分平均功耗依据；若坚持无条件全动态厂保，则应将余项精确写为上述端口耗散/额外主动供能验证，不再要求业务提供内部节点硬波形，也不把尚未完成的假设改成确定材料。选择哪种正式口径应由既定检查契约决定，本文件不修改正式结论。

## 7. 对参考状态与开关/非线性的再检查

- **同源与同控制确实必要。** 参考轨迹必须沿用实际24V源、SPDL边界波形、U5控制，不能拿“全部开”参考去减“切换或失电”实际轨迹。本板四个U5控制固定12V，正常电源已建立时没有来自本控制端的任意门极切换；上电过程另归范围。即使按时变正电导g(t)建模，只要实际与参考同g(t)，瞬时增量耗散仍为g(t)(δv)²；但真实控制电荷注入须另记有源项。
- **二极管适用的是单调静态I-V。** D8/D9/D10的普通正向/稳压支路可作这种工程模型，增量耗散非负；未把它们当0.7V固定源。反向恢复、结电容耦合、存储电荷不能凭静态模型直接覆盖；若其净端口功率不可忽略，应扩充储能/供能，而不是用“二极管无源”一词自动证明增量无源。
- **差平方储能使用恒定正电容模型。** C7、C17、C18、C9、C11都可在正常线性RC工程模型中取任意固定正值，因此未依赖C18准确数值。但实际X7R电容随偏压/温度变化，并不能仅由“物理无源”无条件推出与时变参考轨迹之间同一个差平方储能式；若追求严格非线性电容认证，需要相应电荷模型和增量储能校验。这是本证明的模型边界，不能声称已覆盖所有介质非线性。
- **没有删除原始状态能量。** 实际与参考初始状态不同时SF不为零，C9/C11初值也仍在SC中。周期平均仅在两轨迹均处于有界正常周期/长期稳态、相关储能平均变化为零时消去E'；有限时间上电/任意预充电会保留E(0)-E(T)，本文件未把该项写零。参考是分析轨迹，不能把它的储能当实际零初值。

综合而言，新的推导在“恒正电容、单调二极管、正常同控制U5负载、正常耗散输出级”的工程电路模型内有完整数学链条；它确实摆脱实际端口电压硬界。对原始半导体所有保护/寄生行为，仍缺的是明确端口模型的技术验证。为追求结论而把这些条件省略，会再次变成形式漂亮但范围超出的证明，因此本次不据此修改被冻结的正式结论或输入。
