# Q4 / D10 正常环境温区及热边界独立核查

日期：2026-10-22。仅新增独立证据/推导文档与PDF页截图，未修改原始材料或正式评审卡，未启动额外CLI。

## 结论：两颗均有厂家环境温度曲线覆盖0～70℃

**P12-A03原规则是“有源器件温度等级覆盖项目最低/最高环境温度”。准确厂家PDF已经给出以环境温度Ta为横轴的可耗散功率曲线，Q4和D10的曲线均明确覆盖0～70℃，不能仅因没有独立Ta最小/最大表格就判资料缺失。** 这不是拿存储温区代工作温区，也不是由最高结温高于70℃直接推出环境覆盖。

按本规则的温区覆盖口径，可依据这两条准确厂家环境降额曲线作工程覆盖判断，同时保留相应功率/安装条件。该判断不自动签发整板任意外接负载、任意启动和全部自热状态的合规保证；后者应归实际负载、热设计或接口安全分析，不能在本项临时扩展成阻断条件。

截至本复核读取，`review_out/agent_jobs/P12-A03/Q4`仅有context、research schema及已启动run日志；D10仅有context、research schema。两者尚无本轮正式JSON/analysis，本文件没有引用尚不存在的本轮结论。实际身份另从BOM、连接从原始netlist核对。

## 1. Q4准确身份及环境曲线

`boards/0918全量/cache/mpn/2SC1623_L6_/datasheet.pdf`，4页，Hottech/SHENZHEN HOTTECH ELECTRONICS CO., LTD。

- 第1页：Pc=200mW、RθJA=625℃/W、Tj最高150℃；Tstg=-55～150℃。-55℃属于储存栏，不能写成工作下限。L6是hFE分档，不是温区后缀。
- **第2页右下Pc–Ta曲线**：横轴明确“AMBIENT TEMPERATURE Ta(℃)”，从0℃起至150℃；0～25℃功率200mW，25～150℃线性降为零。该页总标题是Typical Characteristics，曲线关系同时与第1页额定Pc/RθJA一致。
- 环境70℃时，按额定热关系可用功率`(150-70)/625=0.128W`，即约128mW，与图中直线一致。0℃也在厂家画出的正功率平台内，所需环境下限0℃不是靠储存负温度推出来的。

已实际渲染并视觉核查截图：`sources/Q4-temperature-page1.png`、`sources/Q4-temperature-page2.png`。第2页右下图是最直接的温区覆盖原始证据；第1页额定热阻和功率是交叉核对。

## 2. D10准确身份及环境曲线

BOM：D10为ST(先科) 1N5241B，供货码C118660，DO-35。不能混为ST意法半导体，也不能使用旧onsemi缓存替代。

准确PDF：`docs/independent_reviews/2026-10-22/sources/ST-1N5241B-C118660.pdf`，SEMTECH ELECTRONICS LTD./Sino-Tech，1N5220...1N5267，2010-10-28 Rev01，共3页。

- 第1页：Ptot=500mW@Ta25℃，最高Tj200℃，Tstg=-65～200℃；RθJA=0.3K/mW。500mW及热阻的脚注条件为**距管壳8mm处引线保持环境温度**。不能脱离安装条件将500mW直接当任意PCB散热能力。

已实际渲染并视觉核查截图：`sources/D10-temperature-page1.png`、`sources/D10-temperature-page2.png`、`sources/D10-temperature-page3.png`。第3页曲线就是直接的Ta覆盖证据。

## 3. 不扩展规则，但保留真实负载边界

### Q4：板内复位下拉与外部强源不能混算

原始netlist：Q4.1接N_Q4_BASE，经R48=10kΩ接U6.8；Q4.2接地；Q4.3直接接SPDL/CN1.1。板内24V经R4/R52/R47/R46四个120Ω串阻，再经D8/D9到SPDL。正常工程截止时仅漏电，正常充分导通时VCE很低；板内串阻支路最多约24/475.2=50.51mA，即使工程宽取VCE=0.3V，其集电极耗散也仅约15.15mW，低于128mW。不过第1页0.3V的厂家测试是IC100mA/IB10mA，不能无条件称为本板驱动电流下的硬保证；这个数字只是正常充分导通核算示例。

中间线性区不允许用饱和压降代替。仅板内480Ω支路的理论负载线最大功率可接近`24²/(4*475.2)=303mW`，所以“存在限流电阻”不等于任意基极偏置都不会热超限；持续处于线性区是否正常，应由控制功能和实际驱动另行核查。

更关键的是，Q4集电极直接接外部SPDL，没有串在Q4与CN1.1之间的限流电阻。若外部主动源在Q4下拉期间仍强维持0～10V，其电流不经过板内480Ω链；不能用50.51mA代替全部Q4电流。真实接口电流/源阻抗与复位用途决定该附加风险。它是接口与负载核查边界，不会否定厂家Pc–Ta曲线已经证明的0～70℃环境覆盖，也不应因此把P12-A03改写为“厂家没有工作温区”。

### D10：不依赖精确稳压电压的板内直流热量级

D10阴极接DS_ORI，阳极接地；其主要持续供能来自24V四串阻/D8。忽略二极管压降及所有并联负载，任意稳压节点电压v下，板内该支路可向D10提供的功率不超过

`P_D10≤v(24-v)/475.2≤303.1mW`。

这个最大值来自负载线而非把11V稳压假定成所有温度不变；303.1mW低于70℃图示371.4mW。在正常SPDL0～10V域，准确ANBON D9还把N_DS_FEED正向分流至SPDL，常规DS_ORI约在11V以内，D10可能尚未进入明显稳压，实际耗散通常更低。方向及准确来源见`sensor-input-bound-audit.md`、`D9-source-audit.md`。

303.1mW是**主要板内直流源的充分上界**，不能冒充所有周期回灌、任意C17预充电、外灌和安装条件都已验证。C9可以传递周期能量，虽直流开路，不能用“平均电流为零”直接宣布其平均传输功率为零。U5四路正常下拉、R21/R20及D10本身的实际工作点会降低板内源功耗；若要签发全面热保证，应纳入实际周期能量及热安装，而不是要求本温区卡再证明所有工况。

先科热条件为距壳8mm引线保持环境温度，而本BOM封装名含P8.20焊盘跨距；两者不能仅凭数值相近就宣称同一安装条件。环境等级覆盖成立，实际PCB等效热阻/引线温度则应作为热设计适用条件保留。

## 4. 给正式模型的判定建议

1. 先按P12-A03准确规则核对“温区覆盖”。Q4第2页和D10第3页原始Ta降额曲线已提供0～70℃覆盖依据；不再将缺独立Ta区间表或Tj下限表机械当成无温区证据。
2. 正式采用值注明Ta曲线与70℃可耗散功率，不把Tstg负温度改名为工作温度。资料区保留图页和原始额定/安装条件。
3. 本项温区覆盖可作工程通过依据；若卡片同时声称实际热安全，必须另外明确它核查了哪些供能支路和安装条件，不能从温区通过跳成全部热负载通过。
4. 已发现的Q4外部强驱动/线性区及D10安装条件应在证据与边界准确保留，或归接口/热设计后续核查，不遮盖当前温区覆盖已成立的事实；也不要伪装成已确认器件过热。

该处理使用准确型号原始厂家曲线，不需要业务重新确认0～70℃，也不需要业务提供半导体内部电子学推导。
