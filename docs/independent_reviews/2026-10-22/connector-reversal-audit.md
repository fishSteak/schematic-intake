# CN1 / CN2 / H1 防反插与反接边界独立预审

日期：2026-10-22。仅分析，未改正式卡、代码或缓存。

## 1. 检查条款的准确语义

`rules/product_center_15.json` P12-A08：“对外连接器具有防反插结构或受控防呆引脚定义”；备注：“板内非对外连接器不适用；不得凭外壳外形口头升绿”。它允许机械结构或受控引脚/接线防呆方案，并非只检查电气串联二极管。

另一个P14-A02才是“存在反接风险的输入具有反接保护或批准豁免”。两者不能互代：机械防插反不等于散线不会接错；电源二极管也不等于连接器具有防呆。P14-A06涉及外部可插拔供电、带电插拔等，任务书尚未确认的可插拔/带电状态不能直接用来给P12-A08判NA。

## 3. 准确机械资料能证明什么

### CN1

`boards/0918全量/cache/mpn/DB128V-5.08-4P-GN-S/datasheet.pdf`，DORABO客户图，2022-10-27，DB128V-5.08-XXP-C-S。PDF第1页画出固定焊板式螺钉压线端子、5.08mm间距、2～24位变型；4P/GN/S编码与BOM对应。资料没有可拔配对半体或180°配对防呆结构。

因此，“CN1没有反插的线束插头”可用于描述该零件的机械类型；“CN1外部接线不会误接”则没有从该资料得到证明。正确策略应检查是否有按实物朝向定义的端子编号、供电极性和信号标识、受控线束/配线图及安装说明。当前只有电气网表定义，原任务书还特别提醒实物左右方向未等同，不能把它自动视为完整受控防呆方案。

### CN2

准确XYECONN客户图 `cache/mpn/XY-PH2.0-5A11/datasheet.pdf` PDF第1页为XY-PH2.0-NA11家族、5A11=5位、2.00mm间距、直插板端WAFFER，PA66壳体；表列5P尺寸A=8mm、B=12mm。可见壳壁/导向特征，是有壳板端件，不是普通裸5针排针。

但这页没有指定配对线端壳和端子完整料号，也没有给出插反配合阻止/极化公差证明。可以确认存在导向/定位构造；不能仅看照片有壳便宣称指定线束180°绝不可能插反，亦不能宣称电气线序已经无误。最小公开技术补充是准确配对壳/端子图和极化配合关系，整机补充是实际采用的线束线序/方向控制。两类缺口分开，不要都写成业务补料。

### H1

原BOM只写“2.54-1*3P针”，无厂牌/型号，原图第10页为1×3排针符号。可以确认没有已提供的机械极化证据；无法从泛称断言所装配件一定裸露、一定有壳、或一定可由用户外插。

若H1是内部跳帽配置，P12-A08可按范围排除，但须用整机用途/装配说明确认；仍应核对短接1-2与2-3的配置效果。原始2/3脚同网，短2-3只短同网，短1-2把Q1集电极NPN接OUT_ORI，这一电气事实足以支撑配置说明，却不等于现有设计已形成受控防呆。若H1对外连接，则须继续检查其防插反或受控接线方案。

## 4. 全供电路径：D2不能代表整板电气反接保护

原始网表及PDF第2页P01确认：

`CN1.3 / CN2.5 = VCC → F1 → +24V → D2 → VCC24V → U1.VIN → +12V`。

节点上的支路必须全部保留：

- **VCC（F1之前）**：两外部接口同网，可能互相供电；不是各自有独立保护。
- **+24V（F1之后、D2之前）**：C2.1，D2阳极（D2.2）、D3阳极（D3.2）、R4。C2.2接GND；BOM C2=47µF Nichicon UBC1H470MNS1GS，有极性铝电解。
- **VCC24V（D2之后）**：C3.1、U1.3输入、U2.8、U4.8、LED1公共端、R15；C3.2接GND。
- **+12V（U1之后）**：C1.1=4.7µF陶瓷，U3/U5/U6/U7及其他12V支路；C1.2与U1.2接GND。
- **D3另一路**：+24V→D3→N_Q3_SUPPLY→R10/Q3、R6/D4/R9/Q2等输出支路。
- **R4另一路**：+24V→四只120Ω→N_DS_FEED→D8/D9/SPDL/DS网络，不经过D2。
- GND直接连接CN1.4、CN2.1、C2/C3负端、U1地及各IC地，没有总地线串联反接开关。

D2是串联普通LL4148，并非把整个板级电源都放在其后。C1是稳压器后陶瓷，C2是D2前电解，两者保护位置不同，不能混为一谈。

### 明确的电源极性反接候选

若外部将实际VCC与GND接成VCC−GND=−24V，F1仍导通并把+24V节点拉至约−24V；C2正端因此低于其负端约24V。**C2位于D2之前，所以D2反偏阻断后级并不保护C2。** C2反向漏电/击穿形成的回流可经板GND→C2→F1→外部负电源回路，PTC只可能在足够电流/热时间后升阻，不能等同极性阻断或承诺电解不受反向电压。

同时D2/D3可能对其后部分支路提供反向隔离，R4分支仍暴露于反向源；所有信号线外接设备的回流也需按实际线束核对，不能只画VCC入口二极管就声明整板安全。

这条反接候选用于说明**电气保护边界**，不是直接替代P12-A08机械/受控定义结论。若P14-A02另要求反接保护，则D2前C2是独立、具体的未保护对象；不能以“有D2”闭环全板。

### “整排180°反插”与“供电两线互换”不是同一映射

- CN2五针整排反序：1↔5，2↔4，3保持。若线束1原GND、5原VCC，反序会使板VCC/GND相对极性倒置，同时OUT与DS交叉；SIG保持中间脚也不使其安全，因为参考地已变化。
- CN1四针若假设整排反序：1↔4、2↔3，会把外部SPDL送板GND、外部OUT送板VCC、外部VCC送板OUT_ORI、外部GND送板SPDL。它不是简单的VCC/GND两线反接。而本件是散线压接端子，真实风险通常应逐线误接建模，不能凭空套一个并不存在的四针可反插插头。
- H1反向/错位跳帽主要改变1-2与2-3选择，不存在供电脚直接反接模型；若外接整排线束则按用途另定。

| 对象/事项 | 已有足够事实 | 最小剩余归属 | 不应得出的结论 |
