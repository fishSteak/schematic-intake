# R38 / P11-A01 工程判定闭合

日期：2026-10-22。仅本独立文档；未修改正式卡、原始材料或程序。已读AGENTS、当前R38分析、此前R38独立复核、全端口储能文档及用户对照报告。以下区分正常标称工程核算与任意寄生/故障的厂家认证。

## 决定性结论

**本轮正常标称、健康器件、周期平均热功耗口径，可作“工程核算满足”判断。** 该结论不要求精确全局最大，不要求实际SIG_ORI或DS_ORI逐点夹在电源轨内。采用与原图器件结构对应的普通BJT输出级、单调结/导通MOS通道、恒正电容模型，将有源输入电流按远大于手册正常偏置的100µA级预算计入，得到全调节范围反馈电流有效值上界约 **0.949mA**；按TR=110kΩ及50%局部阻段降额，允许有效值约 **1.508mA**，最保守热负荷比约 **0.396**。满阻110kΩ的总平均功耗覆盖约 **10.76mW**，不能把它当可达精确最大或与小阻端最大电流同时取等。

旧卡把“厂家没有给全端口增量耗散认证”继续作为工程模型未成立的理由，标准过高。正常电路核算可以使用准确内部拓扑支持的普通器件模型；应明确模型和余量，而不是要求厂家另开一个并不存在的系统级能量保证。反过来，本结论也不声称任意内部寄生、任意预充电、失电反灌或瞬时滑臂峰值已经认证。

**端部问题主要限制触点/稳定性及全端点厂保式认证，不构成已有功耗超限证据。** 本次在全r范围计算了热负荷，不借10%调节下限；厂家推荐避开端点仍应列为使用规范建议，不能仅因降额图端部空白就令普通功耗核算永久待确认。

## 1. 原始路径与适用工程模型

原始网表/原理图第3、7页：DS_ORI(v)—R21(10k)—x；x经R20(20k)/C7(10nF)到地，经C9(1µF)、R22(a=10k)到n=DS_DELAY；n经Rf=f=R35+r到u=SIG_ORI；C11(2.2pF)跨n/u。R34=10k由u到地。R38.1/.2同接抽头，.3接u，抽头无第三支路。BOM：3296W-1-104LF，100kΩ±10%。

第9/4页DS前端：24V经4×120Ω、D8供能，D8/D9另向实际SPDL=0～10V分流，D10对地，四路U5固定12V控制且另一端各经3.9k到地；C17/C18是对地储能。不存在另一个正常升压源。C18数值未知不妨碍对任意有限正电容的周期能量式。

本轮已确认12/24V标称、0～70℃环境；本项为电阻稳态功耗50%降额。没有把外部SIG/DS需求0～10V倒写成内部硬钳位。用户对照报告的直流隔断/小功耗数量级合理，但其3.6mW“轨差包络”不能覆盖全部耦合瞬态，且不能代替局部阻段降额。

### U7输出供能为什么可以采用正常受控耗散模型

准确TI LM392-N SNOSBT5D第5页图：输出7经Rsc关联Q20上拉发射极、Q21下拉集电极及50µA下拉源；上拉功率来自12V，回流到地。**内部补偿Cc连接内部增益节点，不直接跨接输出7端口。** 偏置源给Cc充电主要改变内部控制量，不是必然新增一个绕过输出级、直接向R38泵能的独立端口。

因此普通集总BJT模型可把输出表示为0/12V供电的受控上拉/下拉及非负输出电阻，或等价的端口相关储能SU、受控电位e∈[0,12]，满足 `SU'≤(e−u)Io`。该模型允许实际u暂时越轨后向输出级返还能量；**不是假定实际u∈[0,12]**。输入过驱动改变e/导通状态，也已包含在模型中。把全部IC静态功耗都再加入R38，或者把Cc的全部偏置能量重复加在Io之上，都会重复计入已由受控输出供能描述的能量。

这不是声称每个微观寄生都严格遵守零余项；是与准确电路结构对应的正常工程模型。若有证据表明正常工作中存在绕过该输出模型的显著主动泵能，才应另计余项。仅以“原厂没有直接写这个不等式”不能否定所有正常模拟电路建模。

### DS前端与输入结

同源、同SPDL边界、同U5控制的开路参考轨迹取C9端口电流为零，参考x电位ex。正电阻、接地电容、单调二极管及正常导通MOS通道满足增量耗散。固定门控的U5没有任意周期门极充电驱动；其体结越轨钳位是向相同供电/地回收或耗能，并非一个未限幅逻辑输出。参考被动骨架的最高独立源24V，故 `0≤ex≤24 R20/(R21+R20)≤16.107V`。被限定的是参考ex，实际v/x可受C9回灌而越过它。

U7.6负向输入PNP接地结不按400nA限流：n<0时向节点注入jc≥0，在合并能量式中贡献 `(n−e)jc≤0`，无需精确−0.3V或夹位电流。U3/U4输入的负向接地结同样作为耗能保护分支，不能把它们的钳位电流全部算成主动输入源。

正常正电位区PNP输入偏置受内部偏置支路限制；正向超共模时输入PNP趋于截止，不会自然变成毫安级主动电源。仍将普通主动输入源显式预算，见第3节，而非默认为零。

## 2. 可复算的平均能量式

令w=x−b、d=n−u、i从x经C9/R22流向n，I38=d/f；向n注入普通主动电流jb，u处其他输入吸收总电流IL（有符号）。原图KCL：

`C9 w'=i`；`C11 d'=i−d/f+j`；`Io=u/R34−i−j+IL`。

前端增量储能、输出端口储能与C9/C11储能合并后：

`E'≤(ex−e)i−a i²−f I38²+(e u−u²)/R34+(n−e)j+(e−u)IL+PF`。

删除已经证明非正的负向接地结项，令h=jb−IL，对i和u分别完成平方。周期/有界长期稳态的储能平均导数为零；有限RC耗散和限幅供电的正常稳定模型给出有界参考/实际轨迹，因此不存在凭空增长的储能项。先计无普通偏置的矩形角点预算：

`B0=max[(ex−e)²/(4a)+e²/(4R34)]`。

a、R34最低9.9k，ex∈[0,16.107]、e∈[0,12]；凸二次式在角点取最大，得到 **B0=7.273mW**。此处不以真实波形同时达到所有角点为前提。

## 3. 普通主动电流不必精确，但必须计入

准确手册正常值：U7输入偏置全温400nA；U3四个LM339输入各400nA；U4的LM358B输入50nA量级；U7比较器输入亦400nA量级。DS前端U2输入约400nA、U4输入约50nA。它们与负向钳位分开处理。

为避免用纳安精度拼保证，本核算把n端普通主动电流及u端合并量分别宽取 **J=100µA、H=100µA**，DS前端普通主动输入总源亦宽取 **100µA**。这些是正常半导体偏置模型的保守工程包络，分别远大于已查正常参数；不是把手册400nA外推成负向钳位保证，也不声称原厂给出了所有故障状态100µA保证。

u项完成平方的增加量不超过 `12H/2+R34 H²/4≈0.625mW`（R34取约10k）；另有 `f I_rms J`。前端普通源不能因实际v可能越轨而简单写成24V×电流：保留差电压下的R21/R20耗散，对其电流源完成平方，最大补偿不超过 `R21 JF²/4+R20 JF²/4`；取上偏约10.1k+20.2k及JF=100µA，向上取 **0.076mW**。该步骤覆盖差电压功率，不要求实际v/ex相等。

向上统一取 `B=7.975mW`，于是

`f I_rms²≤B+f J I_rms`；
`I_rms≤[J+sqrt(J²+4B/f)]/2`。

f≥9.9k给 **I_rms≤0.950mA**。R38总阻TR≤110k时，局部阻体50%允许电流 `sqrt(0.25/TR)≥1.508mA`，因此最保守比例约 **0.397**。满阻r=110k、f≥119.9k时I_rms约0.313mA，`P38≤约10.76mW`。

遗漏项容限也可直接审查：最小允许反馈支路预算是9.9k×0.25/110k=22.5mW，减去B及边界偏置项后，仍可容纳约 **13.03mW** 的额外平均主动供能。这是敏感性阈值，不是假称已经测到一个13mW源。正常结构中没有识别出这样的额外供能通路；若有人以寄生泵能推翻本工程模型，应指出实际通路并证明它可能接近该量级，而非只说所有寄生未获厂家认证。

## 4. 电位器端部：功率核算与使用规范分开

Bourns 3296第1页：0.5W@70℃，TR±10%，绝对最小阻值最大为1%TR或2Ω（取大者），接触阻值变化另列。e/T2413（09/24）第3/4页建议10%～90%、按用段比例降额；第5页缺专用滑臂电流时按全阻额定电流且不超过100mA取值；第6页说明全范围满足规定规格、中段通常更稳定。

厂家推荐端部规避与曲线空白，并不等同已证明端部不能承受低负荷，也不自动把本项改成“必须先获10%～90%业务批准”。本次全r平均电流已经算入R35永久串联限流。用段模型 `Pallow(r)=0.25r/TR` 与 `P38=r I_rms²` 的比值不超过约0.397；r变小不会产生被全阻0.25W掩盖的高功率密度。

精确端点接触/终端材料不是均匀电阻膜，不能把r=0写成所有接触功耗都为零。但普通端部残余阻值≤1%TR≈1.1kΩ量级时，本界对应热耗散至多约 **1mW**；还可与厂家由0.5W/TR得到约2.13mA的正常连续滑臂电流量级比较。这支持低负荷端部的普通热核算，不是微观终端温升/脉冲寿命的独立厂家认证。

**0.950mA是RMS，不是瞬时峰值。** 本项结论为正常稳态/周期平均阻段功率满足；不宣称最大瞬时滑臂电流或任意脉冲均已满足厂家要求。端点稳定性、触点瞬时损伤、生产调校位置应另作建议/相应检查，不能因未做全端部认证而撤销低负荷功耗计算。

## 5. 真正必要与仅影响精度/更严格保证的事项

| 事项 | 本轮处理 |
|---|---|
| 正确反馈接法、准确0.5W/TR额定、50%局部降额 | 必要，原始材料/准确厂家已闭合 |
| C9/C11动态、U7输出和输入供能 | 必要，完整端口能量式及普通半导体耗散模型已显式处理 |
| 普通输入不是绝对高阻开路 | 必要，100µA级工程包络及差电压完成平方已计入 |
| 精确最大值、精确振荡频率、纳安偏流精度 | 不必要，当前充分界有明确余量 |
| 所有内部寄生状态均获厂家端口不等式认证 | 超出普通正常工程模型，不能作为本项默认门槛 |
| 10%～90%项目批准、供电容差/纹波重复确认 | 不是当前标称功耗核算必需业务输入 |
| 任意初始储能、失电反灌、器件损坏、任意外部强驱动 | 不在本次普通正常模型内；未声称保证 |
| 滑臂瞬时峰值/端点稳定性全认证 | 与平均功耗区分，保留范围备注，不冒称已完成 |
