# 工况图生成链路

评审工况图使用PyMuPDF读取PDF、Pillow渲染叠加。本目录的说明图可以使用imagegen，但不能把生成式图片替代正式电路的真实连线定位。

```mermaid
flowchart LR
  A[Agent确定主分析与图规格] --> B[契约及主引用检查]
  B --> C[引脚坐标校准与PDF线段定位]
  C --> D[图类型与方向审计]
  D --> E[完整电路图面与标注排版]
  E --> F[逐页图 总览 元数据]
  F --> G[详情页查看]
  C --> W[定位缺口和告警]
```

## 规格与定位

Agent提供pages、paths、through_body、markers和中文说明。程序按显式主引用选中唯一主分析，其他工况只作文字比较。figure_contract仅兼容等价字段，不从 prose补造支路。

[schematic_routes.py](../../agent_review/schematic_routes.py)结合jlc_project中的设计引脚坐标、板级网络关系及PDF已有线段定位路径；通过坐标校准对应实际PDF。器件内部转接由模型明确声明，不能把外部悬空脚或并联支路任意接成串联。跨页同名网表示逻辑关联，不能跨空白画假铜线。

## 方向与图类型

具体工况使用模型有依据的方向声明。程序识别同一铜边的冲突声明并去掉冲突箭头；这不构成完整极性或KCL证明。cross_case_relations属于供能/储能/耗散关系，程序关闭全部电流箭头并标明非同时导通。

## 裁剪、排版与文件

[stress_path_render.py](../../agent_review/stress_path_render.py)的circuit_crop_box按整页全部电路线和邻近标注求范围，裁去图框/标题栏边角，不仅截所选支路。当前识别依赖该CAD导出的颜色特征；无法识别时保留整页，不猜一个局部裁剪框。

程序叠加路径、器件转接、标注框和引线，先保存每页高清图，再以较小预览拼接总览，降低多页同时驻留内存的压力。flow.png用于总览，step图用于逐页查看，meta.json保存PDF页、图面范围、来源、routing_complete、告警、依据哈希和绘图指纹。

## 缓存与发布

[stress_figures.py](../../agent_review/stress_figures.py)的指纹包含状态、判定、主依据、知识图、文案、相关绘图代码及PDF修改时间等；这是具体实现，不应笼统写成只按图片是否存在复用。完全相同且来源/版本符合条件时才走已有图缓存。

无法构建路线时，部分旧卡可降为定位标注，保留告警；不能统称全部失败都会阻止发布。review.v1和basis-main的特定发布门禁检查路线、引用及图版本一致性。定位完成只说明图形与输入声明对应，不证明整个电路分析正确。

## 展示

统一详情通过图索引取得主图及逐页图片；HTML与Vue都提供图幅切换、缩放和对照。关系图按钮使用“分析关系图”，具体工况使用“工况分析图”。源码仍存在旧适配函数，主调用顺序以stress_figures.run为准。
